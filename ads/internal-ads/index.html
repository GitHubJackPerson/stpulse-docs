    Главная / Товары

    Реклама на уровне артикулов¶

    Раздел показывает рекламные метрики по каждому SKU средствами Юнит-экономики: расходы, показы, клики, конверсии, ROAS, CPM, CPC, CPO, поисковые запросы. В отчёт встроены данные из Performance API (рекламные кампании Ozon) — для каждого артикула видна детализация по кампаниям и поисковым запросам.

    Эта инструкция — про то, как работать с рекламной частью Юнитки. Подробно про сами кампании и стратегии — в разделах Performance API и кабинете рекламы Ozon.

    1. Где найти¶

    1. Откройте Аналитика → Юнит-экономика.
    2. Выберите магазин в левом меню, период — в шапке отчёта (по умолчанию — 30 дней).
    3. Включите готовый набор показателей «Эффективность рекламы».

    После этого в таблице видны рекламные метрики по каждому SKU.

    В разделе «Юнитка» есть второй рекламный набор — «Реклама и Маркетинг»: рекламные расходы из финансовых транзакций (8 типов рекламы + 16 типов маркетинговых акций Ozon). Это другой источник данных, дополнительный к Performance API.

    2. Главные рекламные метрики¶

    В наборе «Эффективность рекламы» для каждого артикула считаются:

    Расходы и доходы¶

    • Расход на рекламу — сколько денег ушло на рекламу этого товара за период (из Performance API).
    • Выручка с рекламы — сколько вернулось продажами через рекламу.
    • ДРР рекламный — доля рекламных расходов от рекламной выручки.

    Стоимость действия¶

    • CPM — стоимость 1000 показов товара.
    • CPC — стоимость одного клика по карточке.
    • Стоимость корзины — сколько в среднем стоит добавление в корзину.
    • CPO — стоимость одного оформленного заказа.

    Конверсии воронки¶

    • CTR рекламный — какой процент увидевших рекламу кликнул.
    • Клик → Корзина — какой процент кликнувших добавил в корзину.
    • Клик → Заказ — какой процент кликнувших оформил заказ.
    • Корзина → Заказ — какой процент положивших в корзину дошёл до оплаты.
    • Показы → Заказы — общая воронка от показа до заказа.

    ROAS¶

    Показывает, сколько рублей выручки приносит каждый рубль рекламного расхода.

    3. Фильтр кампаний¶

    Над таблицей — кнопка «Кампании» с мультиселектом:

    • Поиск по названию кампании.
    • Чипы по статусам с счётчиками: Активная, Архивная, Остановлена, Черновик.
    • Чекбоксы для конкретных кампаний.

    После выбора одной или нескольких кампаний таблица перерисовывается: остаются только артикулы из этих кампаний, метрики считаются именно по этим товарам.

    4. Попап деталей артикула — две вкладки¶

    Кликните на карточку любого артикула в таблице — откроется попап.

    Вкладка «Кампании»¶

    Показывает, в каких рекламных кампаниях участвует этот SKU и с какими результатами по каждой:

    • Расход
    • Показы, клики, CTR
    • Корзины, заказы, модели
    • Выручка от рекламы
    • ДРР, CPO

    Вкладка «Поисковые запросы»¶

    Показывает реальные поисковые запросы, по которым покупатели находят товар на Ozon:

    • Уникальные пользователи — сколько разных людей искали по запросу
    • Просмотры — сколько раз показалась ваша карточка
    • Заказы — сколько купили
    • Конверсия — какой процент увидевших карточку купил
    • Позиция — на каком месте в выдаче по запросу был ваш товар

    Сортировку колонок можно менять кликом по заголовку.

    5. Сценарии использования¶

    Анализ ДРР по магазину¶

    1. Активный набор «Эффективность рекламы», период от 14 дней.
    2. Сортировка по столбцу «ДРР рекламный» убыв.
    3. Видно артикулы, у которых доля рекламного расхода в рекламной выручке самая высокая.
    4. По каждому → попап → вкладка «Кампании» — видно структуру расхода.

    Сравнение двух кампаний¶

    1. В фильтре кампаний выберите первую кампанию.
    2. Запишите итоговые метрики (расход, выручка, ROAS, ДРР).
    3. Снимите фильтр, выберите вторую кампанию.
    4. Сравните.

    Изучение поисковых запросов¶

    1. Откройте артикул, который вас интересует.
    2. → попап → вкладка «Поисковые запросы», сортировка по нужной колонке.
    3. Видно, по каким запросам товар реально показывается, какая конверсия и какая позиция.

    6. Что важно помнить¶

    Подсказка

    Performance API передаёт данные с задержкой 1–3 дня. Самые свежие цифры за вчера и сегодня — это первичная картина, она уточняется в течение 2–3 суток. Серьёзные выводы по эффективности кампании делайте по периоду от 7 дней.

    Важно

    Рекламные метрики из набора «Эффективность рекламы» берутся из Performance API. Маркетинговые акции Ozon (Звёздные товары, Премиум, Бренд-полка и др.) — это отдельная категория, она в наборе «Реклама и Маркетинг» в группе mkt-*. Там расход устроен иначе (не оплата за клик/заказ).

    Частые вопросы¶

    Я нажимаю «Реклама» в меню сайта, а попадаю в Юнит-экономику. Это правильно? Да. Раньше реклама была отдельным разделом, но мы переделали логику: рекламные метрики теперь встроены в Юнитку — там, где видна экономика товара целиком.

    Что значит «маркетинг» в наборе «Реклама и Маркетинг»? Маркетинг (mkt-*) — это участие в акциях Ozon. Например, «Звёздные товары» — фиксированная плата за участие, «Бонусы продавца» — компенсация скидки покупателю, «Премиум» — членский взнос за расширенные возможности. Эти расходы считаются отдельно от Performance-рекламы.

    Цифры в Юнитке отличаются от того, что я вижу в кабинете рекламы Ozon. Почему? - В кабинете Ozon вы видите расходы по моменту списания. В Расчётус — расходы привязаны ко дню заказа. Разница 1–2 дня всегда есть. - В кабинете показано «всё по кампании». В Юнитке — расход распределён между конкретными SKU. Если хотите общую сумму по кампании — раскройте таблицу со всеми SKU кампании и сложите столбец «Расход». - Performance API отдаёт данные с задержкой 1–3 дня.

    Почему по новому артикулу нет рекламных метрик, хотя я вчера запустил кампанию? Performance API отдаёт данные с задержкой 1–3 дня. Через сутки увидите первые цифры, через 3 дня — устойчивую картину.

    Поисковые запросы в попапе показывают позицию «—» или пусто. Что это значит? Это значит, что по этому запросу за период было слишком мало показов вашей карточки, чтобы Ozon рассчитал стабильную позицию.

    Как считается «Выручка с рекламы»? Это сумма, привязанная к заказам, которые сделаны после клика на рекламу за период атрибуции Ozon. Помимо прямых заказов учитываются «модели» — заказы по похожим товарам внутри одной модельной группы.

    Реклама на уровне артикулов — это инструмент для рассмотрения рекламных метрик в разрезе SKU, а не общим итогом по кампаниям. С его помощью видно, как реклама связана с экономикой каждого товара: расход, выручка, конверсия воронки, поисковые запросы. Финальные решения по бюджетам, ставкам и ассортименту — за пределами отчёта, на стороне продавца.
