    Главная / Аналитика

    Юнит-экономика¶

    «Юнит-экономика» (или «Юнитка») показывает экономику по каждому товару (SKU) за выбранный период: для каждого артикула — выручка, себестоимость, реклама, маржа, ROI, рентабельность, конверсии. Если Операционка отвечает на вопрос «когда» (по дням), то Юнитка — на вопрос «что» (по товарам).

    В отчёте десятки настроек: режимы группировки, классификация ролей, фильтр по кампаниям, попап с детализацией, ABC-анализ, цветовые правила, более 90 метрик через 6 предустановленных наборов. Этот раздел проводит по всем возможностям.

    Данные доступны только для Ozon.

    1. Где найти и общий вид¶

    1. Откройте Аналитика → Юнит-экономика.
    2. В шапке выберите магазин (или несколько).
    3. По умолчанию открывается режим «Артикулы» за последние 30 дней.

    Сверху — toolbar с настройками. Под ним — строка пилюль с ролями SKU. Дальше — таблица: артикулы в строках, метрики в столбцах.

    2. Выбор периода¶

    Кнопка «Период» открывает попап:

    • Сетка месяцев для выбора одного или нескольких подряд.
    • Быстрые кнопки «7 дней», «14 дней», «28 дней».
    • Любой произвольный диапазон — выберите два месяца, отчёт пересчитается.

    В отличие от Операционки, у Юнитки нет жёсткого ограничения 2 месяца — можно выбрать квартал, полугодие или год. На длинных периодах расчёт занимает чуть дольше для крупных магазинов.

    3. Три режима группировки¶

    Чипы в toolbar переключают между:

    • Артикулы — плоский список всех SKU магазина с пагинацией по 50 за страницу.
    • Категории — группы по категориям Ozon, с возможностью раскрыть и увидеть артикулы внутри. Подгрузка lazy: первые 5 групп раскрываются автоматически, остальные — по клику.
    • Модели — группы по моделям, которые вы назначили (см. раздел Модели).

    В режимах «Категории» и «Модели» под каждой группой считаются агрегированные метрики (суммарная прибыль, средняя маржа и т.д.) — удобно сравнивать категории между собой.

    4. Роли SKU — пилюли над таблицей¶

    Это уникальная фича Юнитки: автоматическая классификация всех ваших артикулов по ролям. Над таблицей вы видите четыре пилюли:

    Роль Критерий
    💰 Кэш-машины Чистая маржа ≥ 15%
    ↑ Драйверы роста Маржа ≥ 5%, заказы выросли на 20%+ к прошлому периоду
    ≡ Нейтральные Прибыль есть, рост вялый
    ↓ Убыточные Прибыль за период отрицательная

    Каждая пилюля показывает: количество SKU этой роли + суммарную прибыль (зелёная для плюсовых, красная для убыточных).

    Клик по пилюле = фильтр таблицы по этой роли. Активная пилюля подсвечивается, появляется кнопка «Сбросить». Можно выбрать несколько ролей сразу.

    5. Фильтр кампаний¶

    Кнопка «Кампании» открывает мультиселект-дропдаун:

    • Поиск по названию кампании.
    • Чипы по статусам с счётчиками: Активная, Архивная, Остановлена, Черновик.
    • Чекбоксы для конкретных кампаний.

    После выбора одной или нескольких кампаний таблица перерисовывается: остаются только артикулы, которые в этих кампаниях участвуют. Метрики считаются именно по этим товарам.

    Полезно для: сравнения кампаний между собой, аудита конкретной кампании по её артикулам, проверки новой кампании после запуска.

    6. Поиск и быстрые фильтры¶

    Поиск по артикулам¶

    Поле поиска в шапке принимает offer_id, SKU или часть названия. Срабатывает с задержкой 400 мс. Крестик справа очищает.

    Избранное — следить за узким списком¶

    Чип со звёздочкой (слева от чипа «Архивные»). Клик открывает список избранного — там отмечаете товары галочками или загружаете их из файла. Переключатель «Показывать только избранные» оставляет в таблице лишь отмеченные артикулы.

    Удобно, когда следите за узкой группой товаров и не хотите каждый раз искать их вручную. Список избранного в Юнитке — свой, отдельный от списка в Поставках.

    7. Метрики в таблице — 90+ показателей через 6 наборов¶

    В Юнитке очень много метрик. Чтобы не показывать всё подряд, есть 6 готовых наборов:

    • Прибыльность — основа: выручка, прибыль, маржинальность, ROI, ABC.
    • На 1 единицу — экономика per-unit: средняя цена, прибыль на единицу, точка безубыточности.
    • Воронка — показы → клики → корзины → заказы с конверсиями (и в разрезе органика/реклама).
    • Эффективность рекламы — Performance API: CPM, CPC, CPO, CTR, ROAS, ДРР.
    • Реклама и Маркетинг — рекламные расходы по типам (8 рекламных + 16 маркетинговых).
    • Остатки — складские показатели: FBO/FBS, оборачиваемость, дни запаса, стоимость остатков.

    Чипы в toolbar переключают между ними. Активный набор показывает только свои колонки в таблице.

    Свои наборы¶

    Кнопка «+ Набор» позволяет собрать собственный набор:

    1. Откройте дерево из 90+ метрик с чекбоксами.
    2. Отметьте те, что нужны.
    3. Дайте имя.
    4. Сохраните — появится ваш чип в toolbar.

    «Скрыть лишние»¶

    Переключатель: показывать только метрики из активного набора (чисто) или показывать все, но метрики вне набора с приглушённой прозрачностью 35%.

    Метрики без данных скрыты автоматически¶

    Если для всех артикулов в текущем периоде какая-то метрика везде ноль — её колонка не показывается. Это уменьшает шум.

    8. ABC-анализ¶

    В наборе «Прибыльность» есть две специальные колонки: ABC по доходу и ABC по прибыли. Каждый артикул получает бейдж:

    • A (зелёный) — товар входит в группу, дающую первые 80% результата.
    • B (янтарный) — следующие 15%.
    • C (красный) — последние 5%.
    • — (серый) — нет продаж за период.

    Это правило Парето в действии. Сортируйте таблицу по ABC: сверху A → дальше B → внизу C — сразу видна структура ассортимента.

    9. Цветовые правила (тепловая карта)¶

    Цветовые правила — это тепловая карта (heatmap): значения в столбце заливаются градиентом, и аномалии видно сразу, без сортировки.

    В Юнитке цвета работают по столбцам (в отличие от Операционки, где по строкам). В заголовке любого столбца есть иконка кисточки: клик открывает попап с настройкой цвета.

    • Можно выбрать палитру (градиент от красного к зелёному, от белого к синему и т.д.).
    • Минимальные значения подсвечиваются одним оттенком, максимальные — другим.
    • Минимальная интенсивность цвета 12% (чтобы текст оставался читаемым).

    10. Попап деталей артикула¶

    Кликните на карточку любого артикула в таблице — откроется попап с двумя вкладками.

    Вкладка «Кампании»¶

    Показывает, в каких рекламных кампаниях участвует этот SKU и с какими результатами:

    • Расход
    • Показы, клики, CTR
    • Корзины, заказы, модели
    • Выручка от рекламы
    • ДРР, CPO

    Это самый быстрый способ увидеть рекламную картину по конкретному товару — какие кампании дают результат, какие не дают.

    Вкладка «Поисковые запросы»¶

    Показывает реальные запросы покупателей, по которым находят этот товар:

    • Уникальные пользователи
    • Просмотры
    • Заказы
    • Конверсия (просмотры → заказы)
    • Позиция в выдаче

    Сортируйте по любой колонке.

    11. Карточки артикулов и попап моделей¶

    Каждая строка артикула в таблице показывает: фото товара, offer_id жирным, SKU серым.

    Кнопка «Модели» в toolbar открывает попап управления группировкой (тот же что в Операционке). Можно назначить модель вручную для конкретного SKU или массово через XLSX-импорт.

    12. Сценарии использования¶

    Поиск убыточных товаров¶

    1. Кликните пилюлю «Убыточные» над таблицей.
    2. В таблице остаются только SKU с отрицательной прибылью.
    3. Кликните на карточку артикула — откроется попап с детализацией по кампаниям и поисковым запросам.

    Аудит рекламы по магазину¶

    1. Включите набор «Эффективность рекламы», период «30 дней».
    2. Сортировка по столбцу «ДРР рекламный» убыв.
    3. Топ-10 — самые «дорогие» в относительном выражении.
    4. По каждому → попап → вкладка «Кампании» — видно, в каких кампаниях расход концентрируется.

    Поиск точек роста¶

    1. Кликните пилюлю «Драйверы роста».
    2. Видите артикулы, у которых маржа ≥ 5% и заказы растут.
    3. По каждому проверьте текущую рекламу через попап.

    Подготовка к закупке¶

    1. Активный набор «Остатки», сортировка по «Дням запаса» возр.
    2. Топ списка — товары с малым запасом.
    3. Можно скрестить с пилюлями ролей — посмотреть, какие из этих позиций «Кэш-машины» или «Драйверы роста».

    Сбор семантики для новой карточки¶

    1. Откройте артикул, продажи которого вас устраивают.
    2. → попап → вкладка «Поисковые запросы».
    3. Сортировка по «Уникальные пользователи».
    4. Видите, по каким запросам реально находят этот товар на Ozon.

    Пример анализа артикула

    Артикул «Сумка кожаная женская» за 30 дней:

    • Выручка 180 000 ₽, продажи 60 шт, средняя цена 3 000 ₽
    • Себестоимость 90 000 ₽
    • Озон комиссия + фулфилмент 36 000 ₽
    • Реклама 18 000 ₽, ДРР рекламный 18%
    • Прибыль 36 000 ₽, маржа 20%, бейдж ABC = B

    Артикул в роли «Кэш-машина» (маржа выше 15%). Через попап → «Кампании» — видно, в каких кампаниях этот товар откручивается и с каким ДРР по каждой. Через «Поисковые запросы» — по каким запросам его находят.

    13. Что важно помнить¶

    Подсказка

    Не пытайтесь освоить все 90 метрик сразу. Начните с набора «Прибыльность» — он закрывает большинство задач. Когда поймёте, чего не хватает — переключайтесь на нужный набор или собирайте свой.

    Подсказка

    Юнитка показывает данные по периоду без разбивки по дням. Если нужна динамика по дням — открывайте Операционку.

    Частые ошибки¶

    • Анализ только выручки без учёта прибыли. Артикул с выручкой 500 000 ₽ может приносить +50 000 ₽ прибыли или −10 000 ₽ убытка. Без колонки «Прибыль» эти кейсы выглядят одинаково.
    • Сравнение товаров из разных категорий без фильтрации. В разных категориях разная структура расходов и маржи. Сравнения внутри одной категории дают более корректную картину.
    • Использование слишком короткого периода. За 7 дней может быть 2 заказа на артикул, и любая случайная флуктуация искажает выводы. Минимум 30 дней для устойчивых данных.
    • Игнорирование пилюль ролей. Один клик «Убыточные» открывает все проблемные товары — это самый быстрый фильтр.
    • Не используют попап деталей артикула. Без него Юнитка остаётся «таблицей чисел». Попап показывает в каких кампаниях и по каким запросам этот товар реально работает.

    Частые вопросы¶

    Что показывает столбец «Маржинальность»? Долю прибыли в выручке артикула за период. Считается по чистой прибыли — с учётом всех расходов: себестоимости, комиссии, фулфилмента, рекламы.

    Что показывает столбец «ROI»? Возврат на вложенную себестоимость. Удобен, когда нужно сравнить эффективность вложений независимо от объёма продаж.

    Что значит роль «Драйвер роста», если у меня нет рекламы? Это значит: маржа выше 5% И заказы выросли на 20%+ к прошлому периоду. Товар разгоняется органически. Реклама не обязательна для попадания в эту роль.

    Почему в Юнитке нет графиков по дням? По дизайну. Юнитка — это «снимок» по артикулам за период. Если нужна динамика по дням — открывайте Операционку.

    Что делать с убыточными артикулами? Кликните пилюлю «Убыточные» → откройте каждый → попап «Кампании» → видно структуру рекламы по этому товару. Подробный сценарий: Поиск убыточных товаров.

    ABC-анализ — это что? Распределение товаров на три группы по доле в результате: A — топ (первые 80% результата), B — середина (15%), C — хвост (5%). Нумерация автоматическая, считается отдельно по доходу и по прибыли.

    Что значат колонки в попапе «Поисковые запросы»? Это запросы покупателей в поиске Ozon, по которым ваш товар реально показывался. Уникальные пользователи — сколько разных людей искали. Просмотры — сколько раз показалась карточка. Заказы — сколько купили. Конверсия = заказы / просмотры. Позиция — где ваш товар в выдаче по этому запросу.

    Можно ли видеть рекламные расходы из транзакций отдельно от Performance API? Да. Набор «Реклама и Маркетинг» показывает рекламные строки из финансовых транзакций (8 типов рекламы + 16 типов маркетинговых акций Ozon). Набор «Эффективность рекламы» показывает метрики Performance API (CPM, CPC, CPO, ROAS и т.д.). Это разные источники данных, оба полезны.

    Юнитка — главный инструмент для анализа экономики по товарам. Полные данные по каждому SKU в одной таблице: финансы, реклама, воронка, конверсии, остатки. Дальше — фильтры, наборы метрик, попапы для детализации.
