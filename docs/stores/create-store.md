# Создание магазина в STPulse

«Магазин» в STPulse — это контейнер для всех ваших данных по конкретному кабинету Ozon: продажи, остатки, реклама, налоги, себестоимость. Без созданного магазина все разделы сервиса будут пусты — даже если вы оформили подписку и зарегистрировались. Поэтому это первый шаг после регистрации.

Создание магазина занимает 10–15 минут и делится на три части: основные данные, налоговые параметры и подключение Performance API. Налоговые параметры — самое важное: ошибка тут приведёт к неверному расчёту прибыли в финансовых отчётах. Лучше один раз правильно заполнить, чем потом разбираться, почему «у меня прибыль 200 000 ₽ за месяц, а должно быть 350 000».

---

## 1. Открыть форму создания магазина

1. Нажмите на иконку профиля в правом верхнем углу.
2. Выберите пункт **«Магазины»**.
3. Нажмите кнопку **«Добавить магазин»**.

Откроется форма с несколькими блоками — заполняем последовательно.

---

## 2. Основные данные магазина

В верхней части формы:

- **Название магазина** — любое удобное название, по которому вы сможете отличить этот магазин от других в селекторе. Например: «Анна-Декор основной», «Текстиль розница», «Электроника FBO».
- **Seller API Client ID** — копируется из кабинета Ozon.
- **Seller API Key** — секретный ключ Ozon, показывается один раз при создании.

Подробная инструкция, как получить эти ключи: **[Seller API](seller-api.md)**.

Дальше в форме — поля для **Performance API**:

- **Performance API Client ID**
- **Performance API Client Secret**

Подробная инструкция: **[Performance API](performance-api.md)**.

!!! tip "Подсказка"
    Если у вас пока нет рекламы на Ozon, поля Performance API можно пропустить. Подключите потом, когда запустите кампанию. Все основные отчёты (ОПиУ, Операционка, Юнитка финансовая часть) работают и без Performance API.

---

## 3. Налоговые параметры — критически важная часть

В разделе налоговых настроек укажите систему налогообложения и ставки. От этого напрямую зависит, как STPulse будет считать чистую прибыль и применять налоги в отчёте «Прибыли и убытки».

### Система налогообложения

Выберите одну из четырёх:

- **УСН Доходы (6%)** — самая частая для ИП и небольших ООО на маркетплейсе. Налог 6% со всей выручки.
- **УСН Доходы минус Расходы (15%)** — для магазинов с большой долей расходов. Налог 15% от прибыли.
- **ОСНО (с НДС)** — для крупных ООО, обычно с НДС 20%.
- **Патент** — для отдельных категорий, фиксированная сумма налога.

### Ставка УСН

Если выбрана УСН — укажите конкретный процент:
- **6%** — стандартная ставка для УСН Доходы.
- **15%** — стандартная для УСН Доходы минус Расходы.

В некоторых регионах ставка может быть ниже (от 1% до 5%) — уточните у вашего бухгалтера.

### НДС

Если вы плательщик НДС, укажите:
- **Дата начала начисления НДС** — с какой даты применяется ставка (обычно совпадает с переходом на ОСНО).
- **Ставка НДС** — обычно 20%, для отдельных категорий 10% или 0%.

### Дополнительные страховые взносы

Если ваше ИП платит дополнительные страховые взносы (1% с суммы дохода свыше 300 000 ₽), укажите:
- **Дата начала начисления**
- **Процент дополнительных взносов**

!!! warning "Важно"
    Налоговые настройки **критически влияют на чистую прибыль** в ОПиУ и Юнитке. Если выбрать неправильную систему — все цифры в отчётах поползут. Если не уверены — спросите у бухгалтера или начните с УСН 6% (самый частый вариант для оборота до 5–10 млн ₽ в год). Поменять можно в любой момент.

!!! example "Пример"
    Анна — ИП на УСН 6%. При создании магазина:

    1. Выбрала «УСН Доходы», ставка 6%.
    2. НДС — пропустила (на УСН не платит).
    3. Дополнительные взносы — поставила 1% (так как доход ожидается выше 300 000 ₽).

    Результат: в ОПиУ за месяц с выручкой 800 000 ₽ налог рассчитан как 6% × 800 000 = 48 000 ₽ + 1% × 500 000 = 5 000 ₽ доп. взносов. Итог: 53 000 ₽ налогов в строке «Налоги» отчёта.

Подробности по системам налогообложения — в инструкции [Налоги](taxes.md).

## 4. Добавьте 5 сервисных аккаунтов Performance API

Если вы запускаете рекламу на Ozon, рекомендуем создать **5 сервисных аккаунтов Performance API** для ускорения импорта рекламных данных.

1. В кабинете Ozon создайте 5 сервисных аккаунтов в разделе Performance API.
2. В каждом аккаунте создайте ключ (Client ID + Client Secret).
3. В STPulse в разделе Performance API нажмите кнопку **«+»** для добавления каждого нового ключа.
4. Поочерёдно вставьте все 5 пар.

Подробнее: **[Несколько ключей](multiple-keys.md)** и **[Performance API](performance-api.md)**.

!!! tip "Подсказка"
    Один ключ ускоряет импорт в 5 раз по сравнению с одним. Если вы только начали и пока ставите 1 ключ — это нормально, добавите остальные позже без последствий. Главное — не пропускать ключи Seller API.

---

## 5. Сохраните настройки

Нажмите кнопку **«Сохранить»**.

Что произойдёт:

- Магазин появится в списке магазинов.
- Запустится **первичный импорт** — от 30 минут до нескольких часов в зависимости от объёма истории.
- Прогресс импорта виден в карточке магазина: **Профиль → Магазины → Название магазина → Импорт данных**.

После завершения импорта откройте Дашборд «Пульс» — это главный экран. Если на нём появились цифры — магазин подключён правильно.

---

## 6. Что важно помнить

!!! tip "Подсказка"
    Если у вас несколько магазинов в Ozon — создайте отдельную запись в STPulse для каждого. У вас будет возможность анализировать их по одному или вместе (выберите несколько магазинов в шапке любого отчёта — увидите сводный результат).

!!! warning "Важно"
    Не используйте одни и те же Seller API ключи для нескольких магазинов в STPulse. Это приведёт к каше в отчётах: данные одного магазина будут показываться в другом.

## Частые ошибки

- **Неверная роль Seller API** — нужно строго **«admin read only»**, иначе через 1–2 недели начнут пропадать финансовые данные.
- **Перепутаны ключи Seller API и Performance API** — это два разных набора, не взаимозаменяемы.
- **Неправильно выбрана система налогообложения** — например, ИП на УСН 6% выбрал ОСНО → в ОПиУ показываются завышенные суммы налогов и неверная чистая прибыль.
- **Не указана дата начала начисления НДС** — если вы плательщик НДС с конкретной даты, без неё расчёт за прошлые периоды будет неверным.
- **Создан только один Performance API ключ** — рекламные отчёты грузятся в 5 раз медленнее. Решение: создать ещё 4 ключа.
- **Использован один набор ключей для нескольких магазинов** — данные путаются между магазинами, отчёты показывают неверные цифры.

## Частые вопросы

**Сколько магазинов можно создать в одном аккаунте STPulse?**
Зависит от тарифа. На большинстве тарифов лимит достаточно высокий, чтобы покрыть типичные потребности продавца с несколькими магазинами. Проверьте текущий лимит в разделе [Тарифы](../getting-started/tariffs.md).

**Можно ли создать магазин без API-ключей и заполнить позже?**
Технически — да: можно сохранить только название. Но импорт не запустится, отчёты будут пусты. Рекомендуем сразу заполнять все ключи — это занимает 5 минут лишних, но избавляет от необходимости возвращаться.

**Что если налоговые параметры со временем изменятся?**
Зайдите в карточку магазина и обновите. STPulse пересчитает все отчёты с учётом новых настроек. Если у вас был переход с УСН на ОСНО — обязательно укажите дату перехода в полях НДС, иначе расчёт за прошлые периоды будет неверный.

**Какое название магазина выбрать?**
Любое, по которому вы быстро узнаете магазин в селекторе. У продавца с несколькими магазинами часто названия типа «Анна-Декор FBO», «Анна-Декор FBS», «Иван-Электроника основной». Главное — чтобы вы не путались.

**Можно ли удалить магазин потом?**
Да, через настройки магазина. Но при удалении пропадает вся история — будьте уверены, что она вам не нужна. Если магазин временно неактуален — лучше просто не выбирать его в селекторе.

---

Создание магазина — фундамент работы со STPulse. После этого шага все остальные разделы (Финансы, Аналитика, Товары, Поставки) начинают наполняться вашими данными. Дальше — дождаться окончания первичного импорта и переходить к [Дашборду «Пульс»](../dashboard/overview.md) для первого взгляда на магазин.
