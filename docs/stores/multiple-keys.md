# Несколько ключей Performance API

При подключении магазина мы рекомендуем создавать **5 ключей Performance API**, а не один. Это не прихоть — это требование самого Ozon: API имеет ограничения на количество запросов в минуту, и при использовании одного ключа скачивание рекламных отчётов растягивается на часы. С пятью ключами всё то же самое работает в 5 раз быстрее.

Для основных отчётов (ОПиУ, Операционка, Юнитка финансовая часть) Performance API не нужен — они работают на Seller API. Performance API нужен только для **рекламной аналитики**: данные о показах, кликах, конверсиях, ROAS, CPM/CPC/CPO. Если вы не запускаете рекламу на Ozon — можете подключить один ключ или вообще не подключать.

---

## 1. Зачем именно 5 ключей

Каждый ключ Performance API имеет ограничение: **не более N запросов в минуту**. STPulse при ежедневном импорте делает много запросов (по каждой кампании, по каждому магазину, по каждому дню). С одним ключом импорт «упирается» в лимит и встаёт в очередь.

С пятью ключами система распределяет запросы между ними:

- **1 ключ:** импорт за месяц может занять 4–8 часов.
- **5 ключей:** тот же импорт укладывается в 1–2 часа.

Это особенно важно при первичном импорте, когда нужно догрузить 30–60 дней истории сразу.

---

## 2. Как создать 5 ключей в Ozon

1. Откройте кабинет Ozon Seller, зайдите в настройки **Performance API**.
2. Создайте сервисный аккаунт (если ещё нет).
3. Внутри сервисного аккаунта создайте **5 пар Client ID + Key**. Названия можно дать любые — например, `STPulse-1`, `STPulse-2`, … `STPulse-5`.
4. Скопируйте каждую пару — они отображаются в Ozon один раз, после закрытия страницы посмотреть нельзя.
5. Введите все 5 пар в карточку магазина в STPulse — там есть поле для добавления нескольких ключей.

---

## 3. Что если ключей меньше 5?

Меньше 5 — тоже работает, просто медленнее. Импорт пройдёт, но затянется во времени. Если у вас только начало и пока 1–2 ключа — это нормально, добавите остальные позже без последствий.

Главное: **не оставляйте 0 ключей**, если у вас есть рекламные кампании на Ozon. Без Performance API:

- В Юнитке не будет колонок «Расход на рекламу», «CTR», «CPC», «ROAS», «ДРР рекламный».
- В Дашборде «Пульс» субскор «Реклама» в Health Score будет считаться нейтрально (70 баллов), не отражая реальной эффективности.
- Раздел «Реклама» в Юнитке будет пустым.

Расходы на рекламу всё равно появятся в ОПиУ как часть переменных расходов (из транзакций), но без детализации по кампаниям и SKU.

---

## 4. Как обновить или сменить ключи

Ключи Ozon могут «слетать» в нескольких случаях:

- Вы случайно удалили сервисный аккаунт в Ozon.
- Сервисный аккаунт был автоматически отключён за неактивность.
- Сменился владелец магазина.

Чтобы обновить ключи в STPulse:

1. Создайте новые пары Client ID + Key в Ozon.
2. В STPulse откройте карточку магазина → раздел Performance API.
3. Удалите старые ключи, добавьте новые.
4. Дождитесь автоматической пересинхронизации — обычно занимает 30–60 минут.

---

## 5. Что важно помнить

!!! warning "Важно"
    Никогда не передавайте Performance API ключи третьим лицам. С их помощью можно скачать всю вашу рекламную статистику и историю кампаний. Если ключ скомпрометирован — удаляйте его в Ozon и создавайте новый.

!!! tip "Подсказка"
    Если вы планируете подключать сразу несколько магазинов в один аккаунт STPulse — создавайте по 5 ключей **на каждый магазин Ozon**. Использовать один набор ключей для нескольких магазинов нельзя: каждый ключ привязан к конкретному кабинету Ozon.
