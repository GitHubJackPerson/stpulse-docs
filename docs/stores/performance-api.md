# Performance API — рекламные данные Ozon

Performance API — это отдельный канал данных Ozon, через который STPulse забирает информацию о ваших рекламных кампаниях: расходы, показы, клики, конверсии, ROAS, CPM, CPC, CPO и поисковые запросы по каждому SKU. Это **не то же самое, что Seller API** — это разные интерфейсы Ozon с разными ключами и разными правилами авторизации.

Если вы не запускаете рекламу на Ozon — Performance API можно не подключать, основные отчёты (Прибыли и убытки, Операционка, Юнит-экономика финансовая часть) работают и без него. Но как только появляются рекламные кампании — без Performance API вы не увидите, какие из них окупаются, какие сжигают бюджет, и какие ваши товары держат магазин на органике без рекламы.

---

## 1. Где найти Performance API в Ozon

1. Войдите в **личный кабинет Ozon Seller**.
2. Перейдите: **Профиль → Настройки → Performance API**.
3. На странице нажмите **«Создать аккаунт»** (если у вас ещё нет ни одного).
4. После создания у вас появится список с одним или несколькими аккаунтами — у каждого свой числовой ID (например, `90880088`).

В отличие от Seller API, у Performance API структура двухуровневая: сначала вы создаёте **сервисный аккаунт**, потом внутри аккаунта — **ключи (Client ID + Client Secret)**.

---

## 2. Как создать ключ

1. Внутри сервисного аккаунта нажмите **«Добавить ключ»**.
2. Введите любое понятное имя — например, `STPulse Performance` или `STPulse-1`.
3. Нажмите **«Добавить»**.
4. Появятся **два значения**:
   - **Client ID** — публичная часть.
   - **Client Secret** — секретная часть, показывается один раз.
5. Скопируйте оба значения и вставьте в карточку магазина в STPulse в раздел Performance API.

!!! warning "Важно"
    Client Secret показывается **один раз**. Если вы закрыли страницу, не сохранив, — придётся создать новый ключ. Client ID можно посмотреть позже, Client Secret — нет.

---

## 3. Почему рекомендуется 5 ключей

Performance API имеет ограничение: **не более N запросов в минуту с одного ключа**. STPulse при ежедневном импорте делает много запросов (по каждой кампании, каждому SKU, каждому дню). Один ключ упирается в лимит, и импорт растягивается на часы.

С пятью ключами система распределяет запросы между ними:

| Сколько ключей | Время импорта (приблизительно) |
|---|---|
| 1 ключ | 4–8 часов на месяц истории |
| 3 ключа | 1.5–3 часа на месяц истории |
| 5 ключей | 30–60 минут на месяц истории |

Это особенно важно при первичной загрузке, когда нужно подгрузить 30–60 дней истории сразу.

!!! example "Пример"
    Алексей подключил магазин в STPulse и хочет видеть рекламную аналитику.

    1. В Ozon Seller → Профиль → Настройки → Performance API создал **5 сервисных аккаунтов**: «STPulse-1», «STPulse-2», … «STPulse-5».
    2. Внутри каждого аккаунта создал по одному ключу — получил **5 пар Client ID + Client Secret**.
    3. В STPulse в карточке магазина в разделе Performance API нажал «+» и поочерёдно вставил все 5 пар.
    4. Импорт рекламной истории за 30 дней завершился за **40 минут**. С одним ключом этот же объём занимал бы 4–6 часов.

Подробности — в отдельной инструкции **[Несколько ключей](multiple-keys.md)**.

---

## 4. Куда вводить ключи в STPulse

1. Откройте **Профиль → Магазины → Название магазина**.
2. В карточке магазина найдите раздел **Performance API**.
3. Нажмите **«+»** для добавления первого ключа.
4. Вставьте Client ID и Client Secret, нажмите «Сохранить».
5. Повторите для каждого из 5 ключей.

После сохранения первого ключа импорт рекламных данных запустится автоматически. С последующими ключами скорость только возрастает — старые данные не перепроверяются.

---

## 5. Проверка подключения

После добавления ключей и завершения первичного импорта — откройте **Юнит-экономику** (Аналитика → Юнит-экономика). В шапке выберите готовый набор показателей **«Эффективность рекламы»**. Если в таблице появились колонки «Расход на рекламу», «CTR», «CPC», «ROAS», «ДРР рекламный» с числами — значит Performance API подключён правильно.

Если колонки пустые или нулевые:

- Возможно, у вас просто нет активных рекламных кампаний в Ozon — это нормально.
- Возможно, импорт ещё идёт — подождите 30–60 минут.
- Возможно, ключи введены неверно — проверьте в карточке магазина.

---

## 6. Что важно помнить

!!! tip "Подсказка"
    Если рекламы у вас сейчас нет, но планируется — можете подключить Performance API заранее. Импорт будет пустой до запуска первой кампании, но как только реклама заработает, данные начнут приходить автоматически — не нужно потом возвращаться и подключать снова.

!!! warning "Важно"
    Performance API ключ привязан к **конкретному кабинету Ozon**. Если у вас несколько магазинов на разных кабинетах — для каждого нужен свой набор ключей. Использовать один набор для нескольких магазинов нельзя.

## Частые ошибки

- **Подключён только один ключ** — формально работает, но рекламные отчёты грузятся в 5 раз медленнее. Решение: создать ещё 4 ключа в Ozon, добавить в STPulse.
- **Перепутаны Seller API и Performance API ключи** — самая частая ошибка новичков. Это разные системы, ключи не взаимозаменяемы. Seller выглядит как длинная строка, Performance — это пара ID + Secret.
- **Ключ удалён в Ozon** — если вы случайно удалили сервисный аккаунт или ключ в Ozon, импорт остановится. Создайте новый, обновите в STPulse.
- **Аккаунт создан в чужом магазине** — у одного юрлица в Ozon может быть несколько кабинетов. Убедитесь, что вы создаёте Performance аккаунт именно в том кабинете, к которому привязан магазин в STPulse.
- **Не сохранён Client Secret при создании** — Client Secret показывается один раз. Если закрыли окно, не успев скопировать, ключ становится бесполезным. Решение: удалить и создать заново.

## Частые вопросы

**Можно ли использовать один Performance API на несколько магазинов?**
Нет. Performance API строго привязан к кабинету Ozon. Один кабинет = одна группа ключей.

**Что будет, если у меня уже подключён Seller API, а Performance — нет?**
Все основные отчёты (ОПиУ, Операционка, Юнитка финансовая часть) работают. Не работает только рекламная аналитика: в Юнитке будут пустые колонки рекламных метрик, в Дашборде «Пульс» субскор «Реклама» в Health Score будет считаться нейтрально (70 баллов).

**Расходы на рекламу в ОПиУ показываются и без Performance API?**
Да, частично. Рекламные расходы попадают в ОПиУ через финансовые транзакции из Seller API — там есть строки «Маркетинг», «Реклама». Но без Performance API не будет **детализации по конкретным кампаниям и SKU** — только общая сумма.

**Зачем 5 ключей, если 1 тоже работает?**
1 ключ работает, просто медленнее в 5 раз. При первичном импорте за 30 дней истории это 4–8 часов вместо 30–60 минут. При ежедневном импорте — 1–2 часа вместо 10–15 минут. Если вам не критична скорость и вы готовы ждать, можно ограничиться 1–2 ключами. Если хотите быструю аналитику с утра — делайте 5.

**Можно ли посмотреть существующий ключ?**
Только Client ID. Client Secret в Ozon после создания скрыт навсегда. Если вы потеряли Secret — удаляйте этот ключ, создавайте новый.

**Что если у Ozon пропал доступ к Performance API?**
Иногда Ozon временно блокирует Performance API за технические работы или при подозрительной активности. Если ключи в STPulse внезапно перестали работать — сначала проверьте в Ozon, не возникла ли блокировка кабинета. Если в Ozon всё в порядке — пишите в нашу поддержку.

---

Performance API — это инструмент для тех, кто реально работает с рекламой на Ozon. Без него реклама в STPulse — слепое пятно. С ним — у вас в руках детальная картина: какая кампания окупается, какой SKU тянет ROAS вниз, по каким поисковым запросам реально продаётся ваш товар. Подробнее про работу с этими данными — в инструкции [Реклама на уровне артикулов](../ads/internal-ads.md).
