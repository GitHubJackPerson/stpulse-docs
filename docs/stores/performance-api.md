# Performance API — рекламные данные Ozon

Performance API — это отдельный канал данных Ozon, через который Расчётус забирает информацию о ваших рекламных кампаниях: расходы, показы, клики, конверсии, ROAS, CPM, CPC, CPO и поисковые запросы по каждому SKU. Это **не то же самое, что Seller API** — это разные интерфейсы Ozon с разными ключами и разными правилами авторизации.

Если вы не запускаете рекламу на Ozon — Performance API можно не подключать, основные отчёты (Прибыли и убытки, Операционка, Юнит-экономика финансовая часть) работают и без него. Но как только появляются рекламные кампании — без Performance API вы не увидите, какие из них окупаются, какие сжигают бюджет, и какие ваши товары держат магазин на органике без рекламы.

---

## 1. Где найти Performance API в Ozon

1. Войдите в **личный кабинет Ozon Seller**.
2. Перейдите: **Профиль → Настройки → Performance API**.
3. На странице нажмите **«Создать аккаунт»** (если у вас ещё нет ни одного).
4. После создания у вас появится список с одним или несколькими аккаунтами — у каждого свой числовой ID (например, `90880088`).

В отличие от Seller API, у Performance API структура двухуровневая: сначала вы создаёте **сервисный аккаунт**, потом внутри аккаунта — **ключ (Client ID + Client Secret)**.

---

## 2. Как создать ключ

1. Внутри сервисного аккаунта нажмите **«Добавить ключ»**.
2. Введите любое понятное имя — например, `Расчётус Performance`.
3. Нажмите **«Добавить»**.
4. Появятся два значения:
   - **Client ID** — публичная часть.
   - **Client Secret** — секретная часть.
5. Скопируйте оба значения и вставьте в карточку магазина в Расчётус в раздел Performance API.

В отличие от Seller API, ключи Performance API можно посмотреть в кабинете Ozon в любой момент — они не скрываются после создания.

---

## 3. Куда вводить ключи в Расчётус

1. Откройте **Профиль → Магазины → Название магазина**.
2. В карточке магазина найдите раздел **Performance API**.
3. Вставьте Client ID и Client Secret.
4. Нажмите **«Сохранить»**.

После сохранения импорт рекламных данных запустится автоматически.

---

## 4. Проверка подключения

После завершения первичного импорта откройте **Юнит-экономику** (Аналитика → Юнит-экономика). В шапке выберите готовый набор показателей **«Эффективность рекламы»**. Если в таблице появились колонки «Расход на рекламу», «CTR», «CPC», «ROAS», «ДРР рекламный» с числами — значит Performance API подключён правильно.

Если колонки пустые или нулевые:

- Возможно, у вас просто нет активных рекламных кампаний в Ozon — это нормально.
- Возможно, импорт ещё идёт — подождите 30–60 минут.
- Возможно, ключи введены неверно — проверьте в карточке магазина.

---

## 5. Что важно помнить

!!! tip "Подсказка"
    Если рекламы у вас сейчас нет, но планируется — можете подключить Performance API заранее. Импорт будет пустой до запуска первой кампании, но как только реклама заработает, данные начнут приходить автоматически — не нужно потом возвращаться и подключать снова.

!!! warning "Важно"
    Performance API ключ привязан к **конкретному кабинету Ozon**. Если у вас несколько магазинов на разных кабинетах — для каждого нужны свои ключи. Использовать один набор для нескольких магазинов нельзя.

## Частые ошибки

- **Перепутаны Seller API и Performance API ключи** — самая частая ошибка новичков. Это разные системы, ключи не взаимозаменяемы. Seller выглядит как длинная строка, Performance — это пара ID + Secret.
- **Ключ удалён в Ozon** — если вы случайно удалили сервисный аккаунт или ключ в Ozon, импорт остановится. Создайте новый, обновите в Расчётус.
- **Аккаунт создан в чужом магазине** — у одного юрлица в Ozon может быть несколько кабинетов. Убедитесь, что вы создаёте Performance аккаунт именно в том кабинете, к которому привязан магазин в Расчётус.
- **Ключ скопирован не полностью** — иногда из-за выделения теряется первый или последний символ. Расчётус сообщит «неверные ключи». Решение: повторить копирование внимательно.

## Частые вопросы

**Можно ли использовать один Performance API на несколько магазинов?**
Нет. Performance API строго привязан к кабинету Ozon. Один кабинет — одна группа ключей.

**Что будет, если у меня уже подключён Seller API, а Performance — нет?**
Все основные отчёты (ОПиУ, Операционка, Юнитка финансовая часть) работают. Не работает только рекламная аналитика: в Юнитке будут пустые колонки рекламных метрик, в Дашборде «Пульс» субскор «Реклама» в Health Score будет считаться нейтрально (70 баллов).

**Расходы на рекламу в ОПиУ показываются и без Performance API?**
Да, частично. Рекламные расходы попадают в ОПиУ через финансовые транзакции из Seller API — там есть строки «Маркетинг», «Реклама». Но без Performance API не будет **детализации по конкретным кампаниям и SKU** — только общая сумма.

**Можно ли посмотреть существующий ключ позже?**
Да. И Client ID, и Client Secret в Ozon доступны в любой момент: **Профиль → Настройки → Performance API → Ваш аккаунт**. Это удобно: если потеряли ключ, можно скопировать заново без необходимости создавать новый.

**Что если у Ozon пропал доступ к Performance API?**
Иногда Ozon временно блокирует Performance API за технические работы или при подозрительной активности. Если ключи в Расчётус внезапно перестали работать — сначала проверьте в Ozon, не возникла ли блокировка кабинета. Если в Ozon всё в порядке — пишите в нашу поддержку.

---

Performance API — это инструмент для тех, кто реально работает с рекламой на Ozon. Без него реклама в Расчётус — слепое пятно. С ним — у вас в руках детальная картина: какая кампания окупается, какой SKU тянет ROAS вниз, по каким поисковым запросам реально продаётся ваш товар. Подробнее про работу с этими данными — в инструкции [Реклама на уровне артикулов](../ads/internal-ads.md).
