# Магазин и интеграции

Магазин — это «учётная запись Ozon» внутри STPulse. Без подключённого магазина все остальные разделы пусты: нет данных. Поэтому если вы только зарегистрировались — этот раздел нужен в первую очередь, ещё до того, как разбираться с отчётами.

Подключение занимает 15–30 минут и состоит из трёх шагов: создать магазин внутри STPulse, ввести ключи Seller API и ввести ключи Performance API (для рекламной аналитики). После этого начинается **первичный импорт данных** — от 30 минут до нескольких часов в зависимости от размера магазина и периода истории, который вы хотите загрузить. Дальше данные обновляются автоматически каждый день.

---

## 1. Что внутри

В разделе три инструкции:

- **[Создание магазина](create-store.md)** — добавить новый магазин в STPulse, указать налоговые параметры (УСН/ОСН, ставку НДС).
- **[Seller API](seller-api.md)** — получить ключи для основной аналитики Ozon (товары, заказы, возвраты, финансы). Без этих ключей не работает почти ничего.
- **[Performance API](performance-api.md)** — получить ключи для рекламных отчётов (кампании, статистика по показам и кликам). Без них работает всё, кроме раздела «Реклама» в Юнитке.

---

## 2. Правильный порядок

Если впервые подключаете магазин:

1. **Откройте свой кабинет Ozon Seller в новой вкладке.** Большинство шагов идут параллельно: получение ключей в Ozon → ввод в STPulse.
2. **Создайте магазин в STPulse** — сначала пустую запись с названием. Налоговые параметры можно указать сразу или позже.
3. **Получите Seller API ключи** в Ozon: создайте Client ID + Key с ролью «admin read only». Введите в карточку магазина в STPulse.
4. **Создайте сервисный аккаунт Performance API** в Ozon → получите ключ → введите в STPulse.
5. **Дождитесь первичного импорта.** Прогресс виден в карточке магазина. После завершения откроется доступ ко всем отчётам.

!!! tip "Подсказка"
    Performance API можно подключить позже, когда руки дойдут до анализа рекламы. Основные отчёты (ОПиУ, Операционка, Юнитка) работают только на Seller API. Но если у вас **есть запущенные кампании Ozon** — лучше подключить сразу, чтобы рекламные расходы корректно учитывались в финансах.

---

## 3. Типичные ситуации

| Ситуация | Что делать |
|---|---|
| У меня несколько магазинов на одном Ozon-аккаунте | Создавайте по одной записи в STPulse на каждый магазин — у каждого свой Seller ID и ключи |
| Хочу добавить ещё один магазин в STPulse | Просто создайте новую запись — никаких ограничений нет (зависит от тарифа) |
| Сменился Performance API ключ | Обновите ключ в карточке магазина — пересинхронизация запустится автоматически |
| Импорт идёт несколько часов | Это нормально для крупных магазинов с большой историей. Можно закрыть STPulse и зайти позже — импорт идёт в фоне |
| Импорт завершён, но в отчётах пусто | Проверьте период — отчёты по умолчанию за «текущий месяц», а импорт мог поднять прошлый |

---

## 4. Что важно помнить

!!! warning "Важно"
    Используйте роль API-ключа **«admin read only»**, а не «admin». STPulse никогда ничего не меняет в вашем кабинете Ozon — только читает данные. Дать ключу полные права = дать доступ к удалению товаров и кампаний третьим лицам. Не делайте этого.

!!! tip "Подсказка"
    После подключения первого магазина — заходите в [«Пульс»](../dashboard/overview.md). Это главная страница, она покажет общую картину и направит к нужному отчёту, если что-то не в порядке.
