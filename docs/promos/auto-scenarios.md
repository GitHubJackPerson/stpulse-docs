# Автосценарии акций

«Автосценарии» — автоматизация двух действий в кабинете Ozon, связанных с **автодобавлением товаров в акции**. Вы один раз задаёте правило — и сервис выполняет его сам, без ручной работы в кабинете.

Раздел находится в **Акции → Автосценарии** и работает в паре с отчётом [«Аналитика акций»](actions.md): там вы видите, что Ozon добавляет в акции автоматически, а здесь — управляете этим.

!!! info "Что такое автодобавление"
    Ozon может **сам добавлять товары в акции** — без отдельного согласования с продавцом. У товара есть признак «автодобавление в акции», а у части товаров Ozon формирует **список автодобавления**: «Добавим N товаров с такой-то даты». Автосценарии позволяют не отслеживать это вручную каждый день.

Сценарии выполняются **автоматически раз в сутки** утром — сразу после ночного обновления данных по акциям. Каждый прогон попадает в **Историю**.

---

## 1. Два сценария

На вкладке **Сценарии** — две независимые карточки. Каждую можно включить отдельно.

| Сценарий | Что делает |
|---|---|
| **Запрет автодобавления** | Снимает у товаров признак «автодобавление в акции». Товар перестаёт быть кандидатом на автоматическое добавление. Цену товара не трогает. |
| **Удаление из списка автодобавления** | Убирает товары из **списка автодобавления Ozon** — тех, которые Ozon собирается добавить в акцию сам. Товары, уже участвующие в акциях, и ручные участия **не трогает**. |

!!! info "Что сценарии не затрагивают"
    Автосценарии работают только с автодобавлением. Товары, которые **уже участвуют** в акциях (добавлены вручную или Ozon-ом ранее), остаются на месте — сценарии их не выключают.

---

## 2. Включение сценария

У каждой карточки есть **тумблер** и статус — «Включён» или «Выключен».

При включении сервис сначала показывает **предпросмотр**: сколько товаров затронет ближайший прогон и примеры артикулов. Сценарий начнёт работать только после того, как вы **подтвердите** включение в этом окне.

!!! warning "Предпросмотр обязателен"
    Сценарии выполняют реальные действия в вашем кабинете Ozon, поэтому включение всегда проходит через окно подтверждения — вы видите масштаб до того, как что-то изменится.

Выключить сценарий можно в любой момент тем же тумблером.

---

## 3. Исключения — товары, которые сценарий не трогает

Под каждым сценарием — кнопка **«Исключения: N»**. Она открывает список товаров, которые сценарий будет **пропускать**.

- Если список пуст — сценарий применяется **ко всем** подходящим товарам.
- Если в списке есть товары — сценарий обрабатывает всё, **кроме них**.

**Как добавить товары в исключения:**

1. Нажмите **«Добавить»**.
2. Впишите **артикулы или SKU** — по одному в строке или через запятую.
3. Нажмите **«Добавить в список»**.
4. Нажмите **«Сохранить изменения»**.

Список показан таблицей: **фото · артикул · SKU · название**, у каждой строки — крестик для удаления. Есть поиск по списку. Исключения можно задавать и артикулом, и SKU — сервис поймёт оба.

---

## 4. Роли ключа Seller API

Каждый сценарий выполняет запись в кабинет Ozon, поэтому ключу Seller API нужна соответствующая **роль**:

| Сценарий | Нужная роль |
|---|---|
| Запрет автодобавления | **Product** |
| Удаление из списка автодобавления | **Actions** |

Если роли нет — под карточкой появится подсказка, а тумблер будет недоступен, пока роль не добавлена.

**Как добавить роль ключу:**

> Кабинет Ozon → **Настройки → Seller API** → нужный ключ → «⋯» → **Редактировать** → отметьте галочкой нужную роль → **Сохранить**.

---

## 5. История прогонов

Вкладка **История** показывает, что сделали сценарии.

- **Календарь-период** и фильтр по сценарию — над таблицей.
- Сводка: **сегодня** и **всего** — сколько товаров затронуто, и сколько было прогонов.
- Таблица прогонов: **дата · сценарий · артикулы затронутых товаров**.

Так по каждому запуску видно, к каким именно товарам применился сценарий.

---

## Кратко

- **Автосценарии** сами управляют автодобавлением товаров в акции Ozon — раз в сутки.
- **Запрет автодобавления** снимает признак автодобавления; **Удаление из списка автодобавления** убирает товары из очереди Ozon на автодобавление.
- Включение — через **предпросмотр с подтверждением**; **исключения** задают товары, которые сценарий не трогает.
- Нужны роли ключа: **Product** (запрет) и **Actions** (удаление).
- **История** хранит каждый прогон с артикулами затронутых товаров.
