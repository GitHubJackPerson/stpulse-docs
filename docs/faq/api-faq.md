# Вопросы по API Ozon

API — это самая частая зона технических проблем у новых пользователей. Не работают ключи, не подгружается реклама, импорт идёт сутки вместо часа. Здесь разобраны вопросы, которые задают чаще всего, с конкретными причинами и решениями.

Если ответа на ваш вопрос здесь нет — переходите в **[Контакты поддержки](../support/contacts.md)**.

---

## Почему STPulse не показывает данные?

Если после создания магазина и подключения ключей в отчётах пусто — у этого может быть несколько причин:

1. **Импорт ещё идёт.** Первичный импорт занимает от 30 минут до нескольких часов. Откройте карточку магазина → раздел «Импорт данных», там виден прогресс. Если идёт — просто подождите.
2. **Ключ Seller API удалён в Ozon.** Если вы или сотрудник случайно удалили ключ в Ozon Seller — импорт остановится. Создайте новый ключ, обновите в карточке магазина.
3. **Performance API ключи созданы неверно.** Если рекламная часть пустая — проверьте, что подключены Client ID + Client Secret парами, а не в одно поле.
4. **Ключи перепутаны между собой.** Seller API и Performance API — это разные системы. Seller выглядит как одна длинная строка, Performance — это пара ID + Secret. Если перепутали — отчёты не будут работать ни по одной из систем.
5. **Налоговые поля не заполнены.** Без выбранной системы налогообложения некоторые расчёты в ОПиУ показываются нулями.

Если ничего из перечисленного не помогает — пишите в поддержку с указанием названия магазина и времени, когда подключали ключи.

## Можно ли использовать один Seller API для нескольких магазинов?

**Нет.** Каждый магазин в Ozon — это отдельный кабинет с собственным Seller API. Если вы попытаетесь использовать один ключ в нескольких магазинах STPulse, данные будут смешиваться: например, продажи магазина А будут показываться в магазине Б.

Решение: создавайте отдельный Seller API ключ для каждого магазина Ozon, заводите отдельную запись в STPulse под каждый.

## Что будет, если ошибиться в налогах?

Налоговые параметры влияют на расчёт **строки «Налоги»** в отчёте «Прибыли и убытки» и, через неё — на чистую прибыль. Ошибка в выборе системы или ставки приведёт к завышенным или заниженным цифрам.

Например:

- ИП на УСН 6% указал «УСН 15%» → налог в ОПиУ показывается в 2.5 раза больше реального.
- Не указали ставку дополнительных страховых взносов → в годовом отчёте налоги недосчитаны.
- Указали ОСНО вместо УСН → ОПиУ начнёт считать НДС, которого вы не платите.

Хорошая новость: ошибки исправляются в любой момент — зайдите в карточку магазина, измените параметры, отчёты пересчитаются автоматически.

Подробнее: **[Налоги](../stores/taxes.md)**.

## Потерял ключ. Где его посмотреть?

Никак.

Ozon показывает API-ключи **только один раз** — при создании. После закрытия страницы посмотреть нельзя ни в каком месте кабинета. Это сделано из соображений безопасности.

Решение простое: удалите старый ключ в Ozon, создайте новый, обновите в карточке магазина STPulse. Старые данные не потеряются — они уже в базе данных STPulse и сохранятся даже после смены ключей.

## Почему реклама загружается медленно?

Несколько причин:

1. **Неверная роль Seller API.** Если ключ Seller создан с ролью не «Admin read only», некоторые рекламные данные могут не приходить или приходить частично.
2. **Впервые загружаются большие отчёты.** При первичном импорте подгружается 30–60 дней истории — это объективно требует времени. На втором и последующих ежедневных импортах будет в разы быстрее.
3. **Большой объём кампаний.** Если у вас десятки активных кампаний с долгой историей — первичный импорт может идти несколько часов. Это нормально для крупных магазинов.

## Через сколько обновляются данные после операции в Ozon?

Зависит от типа операции:

- **Заказы и продажи** — приходят с задержкой 1–3 дня. Сегодня вы видите вчерашний день почти полностью, позавчерашний и старше — полностью.
- **Финансовые транзакции** — задержка 1–3 дня (часть приходит сразу, часть позже).
- **Возвраты** — задержка 1–7 дней (Ozon регистрирует возврат не сразу).
- **Рекламные данные** — задержка 1–3 дня.
- **Остатки на складах** — обновляются в день импорта (примерно раз в сутки).

Поэтому в STPulse «Дашборд «Пульс»» всегда показывает прибыль за **вчерашний день**, не за сегодняшний — сегодняшний ещё неполный.

## Импорт идёт уже сутки, нормально ли это?

Зависит от размера магазина и объёма истории:

- **Небольшой магазин (до 100 SKU, до 30 дней истории)** — импорт обычно укладывается в 30–60 минут. Если идёт сутки — это аномально, пишите в поддержку.
- **Средний магазин (100–500 SKU, 30–60 дней истории)** — импорт может занимать 2–4 часа.
- **Крупный магазин (500+ SKU, 90+ дней истории)** — может идти 4–8 часов, в редких случаях до суток.
- **Гигант (1000+ SKU с активной рекламой)** — может идти 12–24 часа на первичном импорте.

Если импорт идёт более суток или прогресс не сдвигается часами — пишите в поддержку. Это технический сбой, обычно решается за 1–2 рабочих дня.

## Можно ли проверить статус импорта вручную?

Да. Откройте **Профиль → Магазины → Название магазина → Импорт данных**. Там есть прогресс-бар или метки для каждого типа данных:

- Импорт товаров
- Импорт заказов
- Импорт финансовых транзакций
- Импорт рекламных данных
- Импорт остатков

Если какой-то тип «зелёный» — он завершён. Если «красный» с описанием ошибки — что-то пошло не так.

## Расход на рекламу в STPulse меньше, чем в кабинете рекламы Ozon. Почему?

Несколько причин:

1. **Привязка ко дню.** В кабинете рекламы — расходы на момент списания. В STPulse — расходы привязаны ко дню заказа. Разница 1–2 дня всегда есть.
2. **Распределение по SKU.** В кабинете показано «всё по кампании». В STPulse — расход распределён по конкретным SKU. Если хотите общую сумму по кампании — раскройте набор «Эффективность рекламы» в Юнитке и сложите столбец «Расход».
3. **Performance API задержка** — свежие данные приходят с лагом 1–3 дня.

Если расхождение стабильно больше 5–10% — пишите в поддержку, разберёмся.

Подробнее про расхождения цифр: **[Расхождение цифр с Ozon](numbers-diff-faq.md)**.

## Когда стоит обновлять ключи API?

В большинстве случаев — никогда. Ключи работают, пока вы их сами не удалите в Ozon или Ozon не отключит за неактивность.

Стоит обновить, если:

- Сменился владелец магазина или юрлицо.
- Подозрение на утечку ключа (например, дали посмотреть кому-то из команды и не уверены, что не сохранил).
- Импорт начал стабильно сбоить с ошибкой авторизации.

Замена ключа: создайте новый в Ozon → обновите в карточке магазина STPulse → старый можно удалить в Ozon.

## Что делать, если все ключи работали, а потом резко перестали?

Возможные причины:

1. **Ozon провёл регламентные работы.** Иногда Ozon отключает Performance API на несколько часов для технических работ. Подождите день, проверьте.
2. **Кабинет Ozon заблокирован.** Если у вас есть проблемы с самим Ozon — сначала разбирайтесь там.
3. **Ключи отозваны или удалены случайно.** Проверьте в Ozon, существуют ли ваши ключи. Если нет — создайте новые.
4. **Сменился Ozon ID.** Очень редкий случай, но бывает при смене юрлица — в этом случае нужно полностью пересоздать ключи.

Если ничего не подходит — пишите в поддержку, разберёмся вместе.
