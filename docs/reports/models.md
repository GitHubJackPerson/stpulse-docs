# Модели

Модели — это система группировки товаров в отчётах STPulse.  
С помощью модели можно объединять несколько товаров в одну логическую группу, чтобы смотреть сводные показатели: продажи, остатки, себестоимость, прибыль и другие данные.

---

## 1. Для чего нужны модели

Модели помогают анализировать товар не только по отдельным артикулам, но и по объединённым группам. Это удобно, если:

- у товара есть много размеров одной модели;
- товары объединены в склейку внутри Ozon;
- у бренда много похожих товаров, и их нужно рассматривать вместе;
- один товар представлен в разных цветах или модификациях;
- нужно агрегировать аналитику по группе товаров, а не по каждому SKU отдельно.

!!! tip "Пример"
    Если у вас есть товар «Куртка зимняя» в размерах от XS до 5XL, вы можете задать им модель **«Куртка зимняя классика»** — и анализировать результаты по всей линейке сразу.

---

## 2. Показатели в таблице

Нажав кнопку **«Показатели»**, вы можете выбрать, какие столбцы отображать:

- **Категория**  
- **Название**  
- **Артикул**  
- **Модель**

Это помогает настроить таблицу под ваши задачи и убрать лишние поля.

---

## 3. Как назначить модели вручную

1. Откройте раздел **Отчёты → Модели**.
2. Выберите магазин.
3. Найдите нужный товар через поиск или фильтры.
4. В столбце **Модель** введите название модели вручную.
5. Нажмите Enter — значение сохранится.

Все товары с одинаковым названием модели будут объединены в одну группу во всех отчётах.

!!! warning "Важно"
    Модель должна совпадать **буква в букву** для всех товаров, которые вы хотите объединить.

---

## 4. Импорт моделей из файла XLSX

Если товаров много, удобнее обновлять модели через импорт.

1. Нажмите кнопку **«Импортировать»**.
2. Скачайте шаблон файла — кнопка **«Скачать шаблон с артикулами»**.
3. Откройте файл в Excel или Google Sheets.
4. Заполните два столбца:
    
    - **Артикул**  
    - **Модель**

5. Сохраните файл в формате XLSX.
6. Нажмите **«Импортировать»** и загрузите готовый файл.

После импорта модели сразу обновятся в таблице.

!!! tip "Совет"
    Если у всех товаров одной модели одинаковая часть названия, можно быстро заполнить столбец формулой или копированием.

---

## Пример

Предположим, вы хотите объединить товары:

- кардиган классический L  
- кардиган классический XL  
- кардиган классический XXL  

Вы создаёте модель:

**кардиган классика**


И присваиваете её всем трём артикулам вручную или через XLSX.  
Теперь в отчётах STPulse вы сможете смотреть:

- суммарные продажи по модели,
- общий остаток по всей линейке,
- себестоимость, прибыль, возвраты и другие показатели **по группе в целом**.

## Частые ошибки

- **Лишний пробел в названии модели** — `«куртка зимняя»` и `«куртка зимняя `(с пробелом в конце) — это две разные модели для системы. Товары не объединятся. Решение: использовать копирование, не вводить вручную, проверить пробелы после вставки.
- **Разные написания одной группы** — `«Модель 1»`, `«модель1»`, `«Модель1»`, `«MOdel 1»` — четыре разные модели. Заранее договоритесь с собой о формате (например, всё с заглавной буквы, без пробелов в окончании) и придерживайтесь.
- **Неверный артикул в XLSX** — модель не применится. Особенно частая ошибка при ручном вводе артикулов (опечатки, лишние знаки). Решение: копировать артикулы из STPulse, не печатать вручную.
- **Заменили модель вручную, забыли обновить файл импорта** — при следующем импорте старые модели затрут новые. Решение: всегда сохраняйте актуальный файл с моделями отдельно (Google Sheets, OneDrive), используйте его как «источник правды», вручную правьте только в нём.

## Частые вопросы

**Что лучше — заполнять модели вручную или через импорт?**
Если у вас до 30–50 SKU — вручную быстрее (5 минут). Если 100+ — однозначно через импорт. Импорт даёт ещё одно преимущество: если у нескольких товаров одинаковая часть названия, можно быстро присвоить им модель формулой в Excel.

**Сколько товаров можно объединять в одну модель?**
Сколько угодно. Часто это 4–8 (один товар в разных размерах) или 20–50 (одна модель в разных цветах и размерах). Технических ограничений нет.

**Можно ли удалить модель и сделать товары снова отдельными?**
Да. Очистите столбец «Модель» (вручную или импортом с пустым значением) — товары снова будут показываться отдельными артикулами в отчётах.

**Модели влияют на экономику товара?**
Нет, это чисто визуальная группировка для отчётов. Цены, комиссии, рекламные расходы остаются привязанными к конкретным SKU. Модель просто помогает увидеть сводный результат по группе.

**Можно ли использовать модели для разных целей одновременно?**
Нет, у каждого SKU только одно поле «Модель». Если хотите анализировать тот же набор товаров с разных углов (по сезону, по поставщику, по бренду) — выберите одно главное измерение для модели, остальные используйте через категории и фильтры.

---

Модели — простой инструмент с большой пользой. Когда у вас в одной коллекции 30 размеров одного товара, вместо 30 строк в отчётах вы видите одну строку с суммарными цифрами. Анализировать ассортимент становится в разы проще, особенно у магазинов одежды и обуви, где SKU плодятся быстро.
