# Автобронирование слотов

«Автобронирование слотов» ловит удобный **таймслот приёмки** для черновиков поставок FBO. Свободный слот бронируется сразу по клику, а занятый круглосуточно ждёт фоновый бот-снайпер и бронирует его в тот момент, когда он освободится.

Слоты приёмки у Ozon дефицитны: удобное время разбирают за минуты, а освободиться слот может в любой момент. Ручной способ — сидеть и обновлять страницу — не работает. Снайпер делает это за вас: вы один раз указываете желаемое время, а сервис бронирует его сам, как только оно станет доступно.

Инструмент работает с уже созданными черновиками поставок в статусах **«Заполнение данных»** и **«Готова к отгрузке»** — то есть меняет слот приёмки существующей заявки, а не создаёт поставку с нуля.

---

## 1. Что нужно для работы

Чтобы сервис мог бронировать слоты, у ключа Seller API должна быть роль **Supply order**. Пока её нет, страница видна, но кнопки брони заблокированы, а вверху появляется подсказка.

!!! warning "Добавьте роль «Supply order» ключу Seller API"
    Кабинет Ozon → Настройки → Seller API → Найдите нужный ключ → Нажмите три точки → Редактировать → Отметьте галочкой роль **Supply order** → Сохранить.

---

## 2. Где найти и общий вид

1. Откройте **Логистика → Автобронирование слотов**.
2. Выберите магазин в левом меню.
3. Откроется список черновиков, которым можно задать целевой слот.

Столбцы таблицы:

- **Статус** (первый столбец, иконка) — состояние брони: галочка ✓ — слот забронирован/найден, крутящийся спиннер — идёт бронь или бот ждёт слот, крестик — цель не выполнена.
- **Цель** — заданные желаемые слоты (или серое «забронировать», если цель ещё не задана). Клик открывает пикер выбора времени.
- **Текущий слот** — слот приёмки, который сейчас стоит в поставке.
- **Маршрут** — склад назначения, ниже серым — «из <место сдачи>» (для кросс-докинга).
- **Поставка** — номер заявки, режим (прямая / кросс-док) и статус черновика.

---

## 3. Фильтры и группы

Над таблицей — поиск, период и пилюли-фильтры:

- **Поиск** — по назначению, месту сдачи и номеру поставки.
- **Период** (иконка календаря) — оставить только цели в выбранном диапазоне дат.
- **Режим** — все / прямая / кросс-док.
- **Статус** — все / «Заполнение данных» / «Готова к отгрузке».

Поставки сгруппированы по статусу брони — группы сворачиваются:

- **Завершённые** — слот успешно забронирован. В шапке группы показана историческая аналитика: **успешность** броней (доля успешных) и **среднее время** до брони.
- **В работе** — бронь идёт или бот ждёт освобождения слота.
- **Остальные** — цель ещё не задана.

---

## 4. Как задать цель

1. Нажмите на ячейку **«Цель»** (или «забронировать») в нужной строке.
2. Откроется окно выбора: слева календарь, справа время по группам (Ночь / Утро / День / Вечер).
3. Выберите дату и одно или несколько времён — можно указать несколько запасных вариантов.
4. Нажмите **«Забронировать»**.

Свободные слоты подсвечиваются зелёным. **Свободное** время бронируется сразу, **занятое** будет ловить бот и забронирует его автоматически, как только оно освободится (до срока заполнения поставки).

После нажатия окно закрывается — бронь продолжается сама, следить за ней можно по иконке статуса в первом столбце таблицы.

---

## 5. Что делает бот

После постановки цели бот сам следит за нужным временем и бронирует его, как только оно освобождается — вам не нужно сидеть и обновлять страницу. Чем ближе срок заполнения поставки, тем внимательнее бот следит за слотами.

- **Успешную бронь** видно по галочке и зелёной подсветке строки; вверху появится уведомление.
- **Остановить** ожидание можно кнопкой «Остановить» в окне выбора — она доступна, когда по поставке уже задана цель и бот ждёт слот.

!!! tip "Добавляйте запасные варианты"
    Если удобное время занято, укажите в цели несколько запасных вариантов — бот забронирует первый, который освободится.
