# Остатки

«Остатки» — отчёт по вашим товарам на складах Ozon в системе **FBO**, а если вы торгуете и со своих складов — то и по **FBS/rFBS**. На одном экране видно, сколько единиц каждого товара лежит на каждом складе, в разрезе кластеров (региональных групп складов) и на ваших складах.

Отчёт устроен так же, как Планирование: **товары в строках, склады — в колонках**, склады сгруппированы по кластерам. По каждому пересечению «товар × склад» видно доступный остаток, товар в пути, возвраты и другие метрики. Слева отдельным блоком показаны ваши склады (**FBS**), если они есть. Отчёт только для просмотра — здесь не планируют поставки, а смотрят текущую картину остатков.

Данные берутся из последнего среза остатков Ozon (обновляется раз в сутки; дата среза указана в подзаголовке отчёта).

---

## 1. Где найти и общий вид

1. Откройте **Поставки → Остатки**.
2. В шапке выберите магазин.
3. Откроется таблица: товары слева, склады по горизонтали, сгруппированные по кластерам.

Шапка таблицы трёхуровневая: **Кластер → Склад → Метрика**. Кластеры и склады отсортированы по убыванию доступного остатка — самые «полные» слева (обычно Москва).

!!! info "Кластер и склад — не одно и то же"
    Кластер — это региональная группа складов Ozon. У крупных направлений в кластере несколько складов (например, у Москвы их может быть 8–9), у большинства регионов — один распределительный центр. Поэтому у части кластеров в шапке будет один склад — это нормально.

---

## 2. Режимы: Артикулы, Категории, Модели

Переключатель в тулбаре задаёт уровень детализации строк:

- **Артикулы** — плоский список товаров с остатками.
- **Категории** — товары сгруппированы по категориям Ozon. Группы свёрнуты, показывают итоги; артикулы внутри подгружаются по клику на группу.
- **Модели** — то же, но группировка по моделям товаров.

!!! tip "Сортировка по столбцам"
    В режиме **Артикулы** клик по заголовку любой метрики сортирует таблицу по ней (по возрастанию → по убыванию → сброс). В сгруппированных режимах сортировка отключена, чтобы не смешивать группы и товары.

---

## 3. Метрики склада

По каждому товару на каждом складе доступны метрики:

| Метрика | Что показывает |
|---|---|
| **Доступно** | Единиц готово к продаже |
| **В пути** | Едет на склад |
| **Возврат** | Возвраты от покупателей |
| **К поставке** | Заявлено к поставке, ещё не отгружено |
| **Себестоимость** | Сумма денег в товаре по себестоимости (доступный остаток × себестоимость) |
| **По цене продажи** | Стоимость доступного остатка по цене продажи (цена по акции) — потенциал остатков в деньгах |

Набор и порядок метрик настраиваются через **шестерёнку** справа в тулбаре. По умолчанию **«К поставке»** и **«По цене продажи»** скрыты — включите их галочкой, если нужны.

- **Себестоимость** считается по себестоимости из отчёта «Себестоимость»; если она не задана — показывается 0.
- **По цене продажи** считается по вашей цене по акции (marketingSellerPrice от Ozon) — показывает, сколько денег в остатке при продаже по текущей цене.

## 4. Блок «FBS» — свои склады

Если часть товара вы храните и отгружаете со **своих складов** (FBS/rFBS), их остатки показаны отдельным блоком **слева, перед кластерами Ozon** — сначала ваши склады, затем склады Ozon (FBO).

Блок начинается с итога **«Итого FBS»** (сумма по всем вашим складам для каждого товара), дальше идёт каждый ваш склад по отдельности. Метрики FBS:

| Метрика | Что показывает |
|---|---|
| **Доступно** | Свободный остаток, готовый к продаже |
| **Резерв** | Зарезервировано под заказы |
| **Всего** | Всего на складе (свободный + резерв) |
| **Себестоимость** | Стоимость свободного остатка по себестоимости |

Метрики FBS настраиваются отдельным блоком в **шестерёнке** («Метрики FBS»). Если скрыть все FBS-метрики, блок «FBS» пропадёт из таблицы. По умолчанию **«Всего»** скрыто.

!!! info "Товары только на FBS"
    В отчёт попадают и те товары, у которых остаток есть **только** на ваших складах (FBS), без остатка на FBO. У таких товаров колонки FBO будут пустыми, а FBS — заполнены.

!!! note "Свои склады — плоским списком"
    В отличие от FBO, ваши склады не группируются в кластеры — они показаны просто подряд (обычно их немного), отсортированы по убыванию свободного остатка.

---

## 5. Итоги

В отчёте два вида итогов:

- **«Итого»** — блок сразу за первым столбцом. Для каждого товара это сумма по всем кластерам (сколько всего единиц/денег по этому товару на всех складах).
- **«Итого по столбцам»** — закреплённая строка под шапкой. Для каждого склада и метрики это сумма по всем товарам (сколько всего лежит на этом складе).

---

## 6. Фильтры и управление видом

В тулбаре:

- **Поиск** — по артикулу или SKU.
- **Избранное** — общий список избранных товаров раздела «Логистика» (единый с Планированием). Галочка **«Избранное»** в подзаголовке сужает отчёт до отмеченных товаров, ссылка открывает окно управления списком.
- **Список категорий** — фильтр по категориям товаров.
- **Список кластеров** — дерево кластеров с разбивкой **Россия / СНГ и зарубежье**. Можно скрыть целый кластер или отдельные склады внутри него.
- **Свернуть склады** — скрывает столбцы по складам и оставляет только итоги по кластерам (компактный обзор).

!!! note "Архивные товары"
    Показ архивных товаров управляется общей настройкой отчётов (шестерёнка настроек в шапке сайта), как в остальных отчётах.

---

## 7. Чем «Остатки» отличаются от «Планирования»

«Остатки» показывают **текущую картину** — что и где лежит прямо сейчас. «Планирование поставок» идёт дальше: берёт остатки, добавляет скорость продаж и считает, **сколько и куда довезти**.

Если нужно просто посмотреть распределение товара по складам — открывайте «Остатки». Если нужно решить, что заказывать и куда везти — «Планирование».
