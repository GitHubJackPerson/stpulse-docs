# Остатки

«Остатки» — отчёт по вашим товарам на складах Ozon в системе **FBO**. На одном экране видно, сколько единиц каждого товара лежит на каждом складе, в разрезе кластеров (региональных групп складов).

Отчёт устроен так же, как Планирование: **товары в строках, склады — в колонках**, склады сгруппированы по кластерам. По каждому пересечению «товар × склад» видно доступный остаток, товар в пути, возвраты и другие метрики. Отчёт только для просмотра — здесь не планируют поставки, а смотрят текущую картину остатков.

Данные берутся из последнего среза остатков Ozon (обновляется раз в сутки; дата среза указана в подзаголовке отчёта).

---

## 1. Где найти и общий вид

1. Откройте **Поставки → Остатки**.
2. В шапке выберите магазин.
3. Откроется таблица: товары слева, склады по горизонтали, сгруппированные по кластерам.

Шапка таблицы трёхуровневая: **Кластер → Склад → Метрика**. Кластеры и склады отсортированы по убыванию доступного остатка — самые «полные» слева (обычно Москва).

!!! info "Кластер и склад — не одно и то же"
    Кластер — это региональная группа складов Ozon. У крупных направлений в кластере несколько складов (например, у Москвы их может быть 8–9), у большинства регионов — один распределительный центр. Поэтому у части кластеров в шапке будет один склад — это нормально.

---

## 2. Режимы: Артикулы, Категории, Модели

Переключатель в тулбаре задаёт уровень детализации строк:

- **Артикулы** — плоский список товаров с остатками.
- **Категории** — товары сгруппированы по категориям Ozon. Группы свёрнуты, показывают итоги; артикулы внутри подгружаются по клику на группу.
- **Модели** — то же, но группировка по моделям товаров.

!!! tip "Сортировка по столбцам"
    В режиме **Артикулы** клик по заголовку любой метрики сортирует таблицу по ней (по возрастанию → по убыванию → сброс). В сгруппированных режимах сортировка отключена, чтобы не смешивать группы и товары.

---

## 3. Метрики склада

По каждому товару на каждом складе доступны метрики:

| Метрика | Что показывает |
|---|---|
| **Доступно** | Единиц готово к продаже |
| **В пути** | Едет на склад |
| **Возврат** | Возвраты от покупателей |
| **На заказе** | Заказано у вас Ozon-ом |
| **Стоимость** | Сумма денег в товаре по себестоимости (доступный остаток × себестоимость) |

Набор и порядок метрик настраиваются через **шестерёнку** справа в тулбаре. Метрика «Стоимость» считается по себестоимости из отчёта «Себестоимость»; если она не задана — показывается 0.

---

## 4. Итоги

В отчёте два вида итогов:

- **«Итого»** — блок сразу за первым столбцом. Для каждого товара это сумма по всем кластерам (сколько всего единиц/денег по этому товару на всех складах).
- **«Итого по столбцам»** — закреплённая строка под шапкой. Для каждого склада и метрики это сумма по всем товарам (сколько всего лежит на этом складе).

---

## 5. Фильтры и управление видом

В тулбаре:

- **Поиск** — по артикулу или SKU.
- **Избранное** — общий список избранных товаров раздела «Поставки» (единый с Планированием). Клик открывает окно управления списком; там же тумблер **«показывать только избранные»** сузит отчёт до отмеченных товаров.
- **Список категорий** — фильтр по категориям товаров.
- **Список кластеров** — дерево кластеров с разбивкой **Россия / СНГ и зарубежье**. Можно скрыть целый кластер или отдельные склады внутри него.
- **Свернуть склады** — скрывает столбцы по складам и оставляет только итоги по кластерам (компактный обзор).

!!! note "Архивные товары"
    Показ архивных товаров управляется общей настройкой отчётов (шестерёнка настроек в шапке сайта), как в остальных отчётах.

---

## 6. Чем «Остатки» отличаются от «Планирования»

«Остатки» показывают **текущую картину** — что и где лежит прямо сейчас. «Планирование поставок» идёт дальше: берёт остатки, добавляет скорость продаж и считает, **сколько и куда довезти**.

Если нужно просто посмотреть распределение товара по складам — открывайте «Остатки». Если нужно решить, что заказывать и куда везти — «Планирование».
