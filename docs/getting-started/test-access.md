# Тестовый период

Тестовый доступ позволяет изучить STPulse перед оформлением подписки. В течение 7 дней вы получаете полный функционал сервиса для одного магазина и одного пользователя. Чтобы тест работал корректно, необходимо подключить магазин Ozon с полноценными API-ключами.

---

## 1. Как активировать тестовый доступ

1. После регистрации выберите вариант **«Тестовый доступ»**.
2. Откроется окно активации тестового периода.
3. Введите **Seller API Client Id**.
4. Нажмите **«Оформить период»**.
5. После успешной проверки ключей тестовый доступ активируется автоматически.

!!! warning "Важно"
    Без полного API-доступа сервис не сможет загрузить данные магазина и отображать аналитику.

---

## 2. Где взять Seller API ключи

Для работы STPulse требуется **Seller API** с ролью **admin read only**.

Подробная инструкция находится здесь:  
👉 **[Как получить Seller API ключи](../stores/seller-api.md)**

Кратко:

1. Перейдите в Ozon → **Настройки → API-ключи → Seller API**.  
2. Нажмите **«Создать ключ»**.  
3. Выберите роль **admin read only**.  
4. Скопируйте **Client Id** и **API Key**.  
5. Вставьте **Client Id** в форму тестового доступа STPulse.
6. Полные **Seller API** ключи вставляете **Профиль → Магазины → Ваш магазин Seller API**

---

## 3. Нужно ли подключать Performance API?

Также рекомендуем указать Performance API. Благодаря этому вы получите **детализацию по рекламным кампаниям**. 

👉 **[Инструкция по Performance API](../stores/performance-api.md)**

---

## Пример

Представим, что вы тестируете STPulse для магазина «Спортивная обувь».

**Вы делаете:**

- создаёте Seller API ключи в Ozon с ролью *admin read only*;  
- получаете:
    - Client Id: `a1b2c3-full-client-id`
    - API Key: `d4e5f6-super-secret-key`
- вставляете **Client Id** в окно тестового доступа;  
- нажимаете **«Оформить период»**.
- полные **Seller API** ключи вставляете **Профиль → Магазины → Ваш магазин Seller API**
- полные **Performance API** ключи вставляете **Профиль → Магазины → Ваш магазин Performance API**

**Результат:**

- система подключает магазин;
- загружает первые данные продаж, остатков, заказов и комиссий;
- становится доступен отчёт **Операционка**, **Прибыли и убытки**, **Юнитка**, **Возвраты**;
- если подключён Performance API — появится аналитика рекламных кампаний.

---

!!! tip "Подсказка"
    Если у вас несколько магазинов на одном Ozon-аккаунте, тестовый доступ откроется только для одного. Выберите магазин с наибольшей активностью, чтобы оценить возможности аналитики максимально полно.

!!! warning "Важно"
    - Тестовый доступ можно активировать **только один раз**.  
    - Срок действия: **7 дней**.  
    - Необходимо указать **оба поля** Seller API — Client Id и API Key.  
    - Для рекламной аналитики обязательно подключите Performance API.

---

## Частые ошибки

- **Указан только Client Id** — система не сможет получить доступ к данным. Нужны и Client Id, и API Key (последний — после оформления тестового периода в карточке магазина).
- **Роль ключа отличается от `admin read only`** — STPulse не получает доступ к финансовым данным. Через 1–2 недели начнут пропадать строки в ОПиУ.
- **Неверно вставлен API Key** — обычно из-за неполного копирования (потерянный первый или последний символ). Возникает ошибка авторизации.
- **Пропущено подключение Performance API** — основные отчёты работают, но рекламной аналитики не будет: в Юнитке пустые колонки CPC/ROAS/ДРР.
- **Попытка повторной активации теста после завершения** — тестовый период даётся **один раз** на аккаунт. Если истёк — оформляйте платный тариф.

---

## Частые вопросы

**Что произойдёт, если за 7 дней я не успею всё попробовать?**
Тест автоматически завершится. Данные сохранятся ещё некоторое время (обычно 30 дней) — за это время можно оформить платный тариф и продолжить работу без потерь. Если не оформите — данные могут быть удалены окончательно.

**Можно ли продлить тест ещё на неделю?**
Стандартно — нет, тестовый период даётся один раз. В исключительных случаях (например, если у вас были технические проблемы первые дни) поддержка может пойти навстречу — пишите в Telegram, объясняйте ситуацию.

**В тесте доступны все функции или с ограничениями?**
Доступны все функции — без ограничений. Тест отличается от платных тарифов только тем, что **через 7 дней автоматически завершится**.

**Можно ли активировать тест на двух разных магазинах?**
Тест активируется на аккаунт STPulse, не на магазин. Внутри теста вы можете подключить один магазин (по умолчанию). Чтобы тестировать сразу несколько — сначала разберитесь с одним, потом по итогам теста оформите тариф с дополнительными магазинами.

**Что делать, если за 7 дней не успел загрузить себестоимость?**
Загрузить можно в любой момент после оформления платного тарифа. Себестоимость не пропадает между тестом и подпиской — настройки переносятся автоматически.

---

Тестовый период — это не «ознакомительный режим», а полноценный сервис на 7 дней. Используйте его не на «потыкать кнопки», а на **реальную работу**: подключите магазин, дождитесь импорта, посмотрите отчёты по реальным данным. Через 7 дней у вас будет понимание, нужен ли вам STPulse и какой тариф взять.
