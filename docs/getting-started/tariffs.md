# Тарифы Расчётус

Эта инструкция помогает выбрать подходящий тариф Расчётус, понять, что входит в каждый план, какие есть дополнительные опции и как оформить подписку или тестовый доступ.

---

## 1. Доступные тарифы

На странице тарифов представлены три плана. Чем длиннее срок — тем ниже цена за месяц и больше подарочных месяцев.

### **1 месяц — «Быстрый старт»**
Помесячная оплата без подарочных месяцев. Цена — **5 900 ₽/мес**.

### **6 месяцев — «Уверенный рост»**
Цена — **4 900 ₽/мес**, **+1 месяц в подарок**. Оплачиваете 6 месяцев, пользуетесь 7.

### **12 месяцев — «Максимум выгоды»** *(популярный)*
Самая выгодная цена в пересчёте на месяц — **4 400 ₽/мес**, **+3 месяца в подарок**. Оплачиваете 12 месяцев, пользуетесь 15.

!!! tip "Подарочные месяцы"
    Подарочные месяцы добавляются к сроку доступа автоматически и ничего не стоят. На тарифе 12 месяцев это фактически 15 месяцев работы по цене 12.

---

## 2. Что включено во все тарифы

По умолчанию каждый тариф включает:

- Полный функционал сервиса без ограничений,
- **1 магазин**,
- **5 сотрудников**.

При необходимости можно добавить больше магазинов и сотрудников (см. раздел «Дополнительные опции» ниже).

---

## 3. Тестовый доступ (5 дней)

Все новые пользователи могут активировать **тестовый доступ на 5 дней** — полный функционал Расчётус без ограничений.

Важный нюанс: **5 дней отсчитываются с момента запуска импорта данных**, а не с регистрации. То есть вы можете зарегистрироваться, спокойно подключить магазин и получить ключи Ozon — таймер начнётся, когда сервис начнёт загружать ваши данные.

Чтобы начать тестовый период:

1. Зарегистрируйтесь в Расчётус.
2. Подключите магазин Ozon (Seller API и Performance API).
3. Дождитесь импорта — с этого момента идёт отсчёт 5 дней.

По завершении теста вы сможете выбрать платный тариф без потери данных.

---

## 4. Выбор тарифа

1. Откройте страницу тарифов.
2. Ознакомьтесь с доступными планами.
3. Нажмите **«Выбрать»** под подходящим тарифом.
4. Перейдите к оформлению заказа.

Если вы уже на тестовом периоде, система предложит оформить подписку без потери данных.

---

## 5. Настройка дополнительных опций

Базовый тариф включает 1 магазин и 5 сотрудников. Если нужно больше — добавляются опции.

### **Дополнительный магазин** — *ступенчатая цена*
- 1-й магазин уже включён в тариф.
- **2-й магазин** — **2 900 ₽/мес**.
- **3-й и каждый следующий** — **2 500 ₽/мес**.

### **Дополнительный сотрудник** *(+990 ₽/мес)*
Первые 5 сотрудников включены в тариф. Каждый сверх пятого оплачивается отдельно.

### **Автопродление подписки**
- включено по умолчанию;
- после окончания срока подписка продлевается автоматически.

function calc() {
    const plan = document.getElementById("plan").selectedOptions[0];
    const perMonth = parseInt(plan.value, 10) || 0;
    const months = parseInt(plan.dataset.months, 10) || 1;
    const bonus = parseInt(plan.dataset.bonus, 10) || 0;

    const extraShops = parseInt(document.getElementById("shops").value, 10) || 0;
    let shopsCost = 0;
    if (extraShops >= 1) {
        shopsCost = 2900 + Math.max(0, extraShops - 1) * 2500;
    }

    const extraUsers = parseInt(document.getElementById("users").value, 10) || 0;
    const usersCost = extraUsers * 990;

    const totalPerMonth = perMonth + shopsCost + usersCost;
    const totalForPeriod = totalPerMonth * months;

    document.getElementById("total-month").textContent = totalPerMonth.toLocaleString("ru-RU");
    document.getElementById("total-period").textContent = totalForPeriod.toLocaleString("ru-RU");
    document.getElementById("access-months").textContent = months + bonus;
}

if (document.readyState !== "loading") {
    calc();
} else {
    document.addEventListener("DOMContentLoaded", calc);
}

!!! warning "Про калькулятор"
    Калькулятор считает базовую стоимость и не учитывает промокоды. Итоговую сумму со скидкой всегда показывает страница оформления заказа — она авторитетна.

## 6. Промокоды

Если у вас есть промокод:

1. Введите его в поле **Промокод** на странице оформления.
2. Нажмите **«Применить»**.
3. Система автоматически пересчитает стоимость заказа.

---

## 7. Оформление подписки

1. Проверьте выбранный тариф и дополнительные опции.
2. Ознакомьтесь с итоговой суммой.
3. Поставьте галочку принятия условий оферты.
4. Выберите способ оплаты:
   - **Перейти к оплате** — онлайн-оплата банковской картой,
   - **Получить счёт для оплаты** — для ИП и юридических лиц.

После оплаты тариф активируется автоматически.

---

!!! warning "Важно"
    Если отключить автопродление, обновление данных остановится после окончания текущей подписки. Уже загруженные отчёты остаются доступными.

## Частые ошибки

- **Выбран тариф без учёта количества магазинов.** Если у вас 3 магазина, заложите сразу 2 дополнительных в калькулятор — иначе при оформлении придёт счёт с базовой стоимостью, и докупать опции потом неудобно.
- **Лишние сотрудники в опциях.** Первые 5 сотрудников уже включены. Доплачивать за шестого имеет смысл, только если у него действительно будет отдельный аккаунт.
- **Промокод введён неверно или просрочен.** Проверьте регистр букв (некоторые промокоды чувствительны) и срок действия.
- **Не поставлена галочка условий оферты.** Оплата не проходит без согласия с условиями — это формальное требование.

## Частые вопросы

**Что выгоднее — тариф на 1 месяц или сразу на год?**
Годовой выходит заметно дешевле в пересчёте на месяц (4 400 ₽ против 5 900 ₽) и добавляет 3 месяца в подарок — фактически 15 месяцев по цене 12. Если вы уже понимаете, что будете пользоваться сервисом — берите годовой. Если только пробуете — начните с 1 месяца, разберётесь, потом продлите.

**Сколько сотрудников можно завести бесплатно?**
Пять — они входят в любой тариф. Каждый сверх пятого — +990 ₽/мес.

**Сколько стоит второй и третий магазин?**
Второй магазин — 2 900 ₽/мес, третий и каждый следующий — 2 500 ₽/мес. Первый магазин включён в тариф.

**Можно ли изменить тариф в середине срока?**
Да, через поддержку. Перейти на более дорогой можно с доплатой разницы. Перейти на более дешёвый — обычно с момента следующего периода.

**Что будет с моими данными при окончании подписки?**
Данные не удаляются сразу — они сохраняются ещё какое-то время (обычно 30 дней), за этот период можно продлить подписку и продолжить работу без потерь.

**Можно ли сначала включить опцию «Дополнительный магазин», а потом отключить?**
Да. Опция платная помесячно. Если перестанете пользоваться — отключайте через настройки или поддержку, дальнейших списаний не будет.

**Промокод даёт скидку только на первый период или на все продления?**
Зависит от конкретного промокода. Большинство — только на первый период. Точные условия указаны при применении промокода на странице оформления.

---

Тариф — это договорённость на длинный отрезок времени. Лучше один раз взять на год с правильным набором опций, чем каждый месяц возвращаться к этому вопросу. Если сомневаетесь — пишите в поддержку, поможем подобрать нужный план под ваш масштаб магазина.
