# Эффективность рекламы

Сценарий — пошаговый маршрут аудита рекламы средствами Юнит-экономики. Использует наборы рекламных показателей, фильтр кампаний, попап деталей артикула с вкладками «Кампании» и «Поисковые запросы».

---

## 1. Подготовка

Перед началом проверьте:

- **Performance API подключён** в карточке магазина. Без него рекламные метрики будут отсутствовать.
- **Себестоимость загружена** (для корректного расчёта маржи и прибыли).

---

## 2. Открыть Юнит-экономику

1. Откройте **Аналитика → Юнит-экономика**.
2. В шапке выберите магазин и период (например, последние 30 дней).
3. Включите готовый набор показателей **«Эффективность рекламы»**.

После этого в таблице видны рекламные метрики по каждому SKU:

- Расход на рекламу, выручка с рекламы
- CPM, CPC, стоимость корзины, CPO
- CTR рекламный
- Конверсии: клик→корзина, клик→заказ, корзина→заказ
- ДРР рекламный

---

## 3. Сортировка и просмотр

Сортируйте таблицу по столбцу **«ДРР рекламный»** убыв. — увидите артикулы, у которых доля рекламного расхода в рекламной выручке самая высокая.

Сортировка по другим столбцам:

- **«Расход на рекламу»** убыв. — где сосредоточен бюджет.
- **«Выручка с рекламы»** убыв. — какие SKU реклама приводит к продажам.
- **«CPO»** убыв. — где стоимость заказа выше.

---

## 4. Анализ по конкретному артикулу

Кликните на карточку артикула — откроется попап с двумя вкладками.

### Вкладка «Кампании»

Видно, в каких рекламных кампаниях участвует этот SKU и с какими результатами по каждой:

- Расход
- Показы, клики, CTR
- Корзины, заказы, модели
- Выручка от рекламы
- ДРР, CPO

Это самый прямой способ увидеть, где именно у конкретного товара формируется рекламный расход — в одной кампании, нескольких, или равномерно.

### Вкладка «Поисковые запросы»

Видно, по каким запросам покупатели находят этот товар на Ozon:

- Уникальные пользователи
- Просмотры
- Заказы
- Конверсия (просмотры → заказы)
- Позиция в выдаче

Сортируйте по любой колонке.

---

## 5. Фильтр по конкретной кампании

Если нужно проанализировать одну рекламную кампанию целиком:

1. Кнопка **«Кампании»** в toolbar.
2. В мультиселекте выберите нужную кампанию.
3. Таблица перерисуется: останутся только артикулы из этой кампании, метрики посчитаются по ним.

Полезно для сравнения двух кампаний между собой или анализа новой кампании после запуска.

---

## 6. Метрики

- **ROAS** — сколько рублей выручки приносит каждый рубль рекламного расхода.
- **ДРР рекламный** — доля рекламного расхода в рекламной выручке (в процентах).
- **CPO** — стоимость одного оформленного заказа из рекламы.

---

## 7. Что важно помнить

!!! tip "Подсказка"
    Юнитка показывает данные за выбранный период. На коротких периодах (1–3 дня) рекламные метрики могут сильно колебаться: алгоритмы Ozon продолжают обучать кампании после запуска. Для устойчивых данных лучше период от 14 дней.

!!! warning "Важно"
    Performance API отдаёт данные с задержкой 1–3 дня. Самые свежие цифры за вчера и сегодня — это первичная картина, она будет уточняться в течение 2–3 суток.
