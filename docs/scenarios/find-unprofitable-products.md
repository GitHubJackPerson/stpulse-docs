# Поиск убыточных товаров

Сценарий — пошаговый маршрут работы с **Юнит-экономикой** для поиска SKU с отрицательной прибылью и анализа причин. Использует пилюли ролей, наборы показателей, попап деталей артикула.

Сценарий рассчитан на 30 минут работы.

---

## 1. Подготовка

Перед началом проверьте, что у вас в порядке:

- **Себестоимость загружена** (раздел Финансы → Себестоимость). Без неё расчёт прибыли неполный — в нём не учтены закупочные цены.
- **Период анализа** — стандартно 30 дней. Можно длиннее, если хотите более устойчивые данные.

---

## 2. Открыть Юнит-экономику

1. Откройте **Аналитика → Юнит-экономика**.
2. В шапке выберите магазин.
3. По умолчанию открывается режим «Артикулы» за последние 30 дней.

---

## 3. Применить фильтр «Убыточные»

Над таблицей — четыре пилюли с ролями SKU:

- 💰 Кэш-машины
- ↑ Драйверы роста
- ≡ Нейтральные
- ↓ **Убыточные** ← вам сюда

Кликните пилюлю **«Убыточные»**. В таблице остаются только SKU с отрицательной прибылью за период.

На пилюле сразу видны:

- **Количество SKU** — сколько артикулов с минусовой прибылью.
- **Сумма прибыли** красным цветом — общий минус по этой группе.

---

## 4. Анализ по каждому артикулу

Для каждого убыточного SKU посмотрите детализацию:

### Колонки в таблице

Включите набор **«Прибыльность»** — увидите главные финансовые метрики:

- Выручка, прибыль, маржинальность
- Себестоимость
- ABC-бейдж

Включите набор **«Эффективность рекламы»** — увидите рекламные метрики:

- Расход на рекламу
- Выручка с рекламы
- ROAS, ДРР рекламный
- CPM, CPC, CPO

Переключаясь между наборами, видно: убыточность связана с маржой, рекламой, низкой ценой или комбинацией.

### Попап деталей артикула

Кликните на карточку артикула — откроется попап с двумя вкладками:

- **«Кампании»** — какие рекламные кампании работают по этому SKU и с какими результатами (расход, ROAS, ДРР по каждой).
- **«Поисковые запросы»** — по каким запросам покупатели находят товар на Ozon.

Через попап «Кампании» видно структуру рекламного расхода: одна кампания может тянуть всю экономику артикула вниз, или расход распределён равномерно.

---

## 5. Связанная информация

Чтобы понять полную картину по артикулу, можно открыть дополнительные разделы:

- **[Возвраты](../analytics/returns.md)** → введите SKU в поиск, увидите процент возвратов и причины.
- **[Поставки → Планирование](../supplies/supply-planning.md)** → найдите тот же SKU в таблице, увидите остатки и дни запаса.

---

## 6. Что показывает Юнитка по убыточному артикулу

| Метрика | Что показывает |
|---|---|
| Прибыль | Финансовый итог по артикулу (с учётом всех расходов и рекламы) |
| Маржинальность | Доля прибыли в выручке артикула за период |
| ROI | Возврат на вложенную себестоимость |
| ROAS / ДРР рекламный | Эффективность рекламы по этому SKU |
| ABC | Доля артикула в общем результате магазина |

Числа в этих колонках — основа для решения. Само решение (что делать с убыточным SKU) — за вами.

---

## 7. Что важно помнить

!!! tip "Подсказка"
    Юнитка — инструмент анализа, не действий. Она показывает экономику по каждому SKU и даёт детализацию по кампаниям и запросам. Решение «что делать» с конкретным товаром (изменять цену, перенастроить рекламу, снять с продаж) — управленческое, оно за пределами этого отчёта.

!!! warning "Важно"
    На коротких периодах (7–14 дней) данные по конкретному SKU могут быть нерепрезентативны: одна-две случайные сделки сильно влияют на маржу. Для устойчивых выводов используйте период от 30 дней.
