# Юнит-экономика

«Юнит-экономика» (или «Юнитка») отвечает на главный вопрос: **какие товары реально зарабатывают деньги, а какие — нет**. Если в магазине 100 артикулов, обычно 20 из них приносят 80% прибыли, а 20 — стабильно тянут общий результат вниз. Юнитка показывает это в одной таблице: для каждого SKU — выручка, себестоимость, реклама, маржа, ROI, рентабельность, конверсии — за выбранный период.

В отличие от Операционки, которая про «когда» (по дням), Юнитка про «что» (по товарам). Это инструмент стратегических решений по ассортименту: что масштабировать, на чём поднять цену, что снять с продаж, куда вложить рекламный бюджет.

В отчёте десятки настроек: режимы группировки, классификация ролей, фильтр по кампаниям, попап с детализацией, ABC-анализ, цветовые правила, более 90 метрик через 6 предустановленных наборов. Этот раздел проводит по всем возможностям.

Данные доступны только для Ozon.

---

## 1. Где найти и общий вид

1. Откройте **Аналитика → Юнит-экономика**.
2. В шапке выберите магазин (или несколько).
3. По умолчанию открывается режим «Артикулы» за последние 30 дней.

Сверху — toolbar с настройками. Под ним — **строка пилюль с ролями SKU** (новинка 2026-04-28). Дальше — таблица: артикулы в строках, метрики в столбцах.

---

## 2. Выбор периода

Кнопка **«Период»** открывает попап:

- **Сетка месяцев** для выбора одного или нескольких подряд.
- **Быстрые кнопки** «7 дней», «14 дней», «28 дней».
- **Любой произвольный диапазон** — выберите два месяца, отчёт пересчитается.

В отличие от Операционки, у Юнитки **нет жёсткого ограничения 2 месяца** — можно выбрать квартал, полугодие или год. Помните: чем длиннее период, тем больше данных надо прогрузить (для крупного магазина с 1000+ SKU это может быть 5–10 секунд).

---

## 3. Три режима группировки

Чипы в toolbar переключают между:

- **Артикулы** — плоский список всех SKU магазина с пагинацией по 50 за страницу. Самый детальный режим.
- **Категории** — группы по категориям Ozon, с возможностью раскрыть и увидеть артикулы внутри. Подгрузка lazy: первые 5 групп раскрываются автоматически, остальные — по клику.
- **Модели** — группы по моделям, которые вы назначили (см. раздел [Модели](../reports/models.md)).

В режимах «Категории» и «Модели» под каждой группой считаются агрегированные метрики (суммарная прибыль, средняя маржа и т.д.) — удобно сравнивать категории между собой.

---

## 4. Роли SKU — пилюли над таблицей

Это уникальная фича Юнитки — автоматическая классификация всех ваших артикулов по бизнес-ролям. Над таблицей вы видите четыре пилюли с цветными иконками:

| Роль | Критерий | Что значит |
|---|---|---|
| 💰 **Кэш-машины** | Чистая маржа ≥ 15% | Стабильно прибыльные товары — ваш «хребет» магазина |
| ↑ **Драйверы роста** | Маржа ≥ 5%, заказы выросли на 20%+ к прошлому периоду | Восходящие звёзды — стоит вкладывать в рекламу |
| ≡ **Нейтральные** | Прибыль есть, но рост вялый | Стабильные середняки, специальной работы не требуют |
| ↓ **Убыточные** | Прибыль за период отрицательная | Здесь вы теряете деньги — нужно срочно разбираться |

Каждая пилюля показывает: **количество SKU** этой роли + **суммарную прибыль** (зелёная для плюсовых, красная для убыточных).

**Клик по пилюле** = фильтр таблицы по этой роли. Активная пилюля подсвечивается, появляется кнопка «Сбросить». Можно выбрать несколько ролей сразу.

!!! tip "Подсказка"
    Это самый быстрый способ найти проблемные товары. Один клик по «Убыточным» — и в таблице остались только SKU, которые тянут прибыль вниз. Дальше открывайте каждый, разбирайтесь, что с ним делать.

---

## 5. Фильтр кампаний

Кнопка **«Кампании»** открывает мультиселект-дропдаун:

- **Поиск** по названию кампании — удобно, если у вас десятки запущенных.
- **Чипы по статусам** с счётчиками: Активная, Архивная, Остановлена, Черновик.
- **Чекбоксы** для конкретных кампаний.

После выбора одной или нескольких кампаний таблица перерисовывается: остаются только артикулы, которые в этих кампаниях участвуют. Метрики считаются именно по этим товарам.

Полезно для: сравнения кампаний между собой, аудита конкретной кампании по её артикулам, проверки новой кампании после запуска.

---

## 6. Поиск по артикулам

Поле поиска в шапке принимает offer_id или часть названия. Срабатывает с задержкой 400 мс (чтобы не дёргать сервер при каждом нажатии). Крестик справа очищает.

Удобный сценарий: ввели SKU → увидели все его метрики → кликнули на карточку → открыли детальный попап с кампаниями и поисковыми запросами.

---

## 7. Метрики в таблице — 90+ показателей через 6 наборов

В Юнитке очень много метрик. Чтобы не показывать всё подряд, есть **6 готовых наборов**:

- **Прибыльность** — основа: выручка, прибыль, маржинальность, ROI, ABC.
- **На 1 единицу** — экономика per-unit: средняя цена, прибыль на единицу, точка безубыточности.
- **Воронка** — показы → клики → корзины → заказы с конверсиями (и в разрезе органика/реклама).
- **Эффективность рекламы** — Performance API: CPM, CPC, CPO, CTR, ROAS, ДРР.
- **Реклама и Маркетинг** — рекламные расходы по типам (8 рекламных + 16 маркетинговых).
- **Остатки** — складские показатели: FBO/FBS, оборачиваемость, дни запаса, стоимость остатков.

Чипы в toolbar переключают между ними. **Активный набор** показывает только свои колонки в таблице — без шума.

### Свои наборы

Кнопка **«+ Набор»** позволяет собрать собственный набор:

1. Откройте дерево из 90+ метрик с чекбоксами.
2. Отметьте те, что нужны.
3. Дайте имя.
4. Сохраните — появится ваш чип в toolbar.

Свои наборы хранятся в браузере. Очень удобно: например, «Утренняя проверка» (5 метрик), «Анализ рекламы по понедельникам» (12 метрик), «Подготовка к закупке» (остатки + продажи).

### «Скрыть лишние»

Переключатель: показывать только метрики из активного набора (чисто) или показывать все, но метрики вне набора с приглушённой прозрачностью 35%.

### Метрики без данных скрыты автоматически

Если для всех артикулов в текущем периоде какая-то метрика везде ноль — её колонка не показывается. Это уменьшает шум.

## 8. ABC-анализ

В наборе «Прибыльность» есть две специальные колонки: **ABC по доходу** и **ABC по прибыли**. Каждый артикул получает бейдж:

- **A** (зелёный) — товар входит в группу, дающую первые **80% результата**. Это ваши главные товары.
- **B** (янтарный) — следующие **15%**.
- **C** (красный) — последние **5%**, низкоэффективные позиции.
- **—** (серый) — нет продаж за период.

Это знаменитое правило Парето в действии. Если у вас 100 SKU, обычно 15–20 из них имеют ABC=A — они и приносят основной результат.

Сортируйте таблицу по ABC: сверху A → дальше B → внизу C. Сразу видна структура ассортимента.

---

## 9. Цветовые правила (градиент в столбцах)

В Юнитке цвета работают **по столбцам** (в отличие от Операционки, где по строкам). В заголовке любого столбца есть **иконка кисточки**: клик открывает попап с настройкой цвета.

- Можно выбрать палитру (градиент от красного к зелёному, от белого к синему и т.д.).
- Минимальные значения подсвечиваются одним оттенком, максимальные — другим.
- Минимальная интенсивность цвета 12% (чтобы текст оставался читаемым).

Полезно для:

- **Прибыли**: красные → убыточные SKU, зелёные → главные деньги.
- **Маржи**: чтобы видеть, кто продаётся ниже плановой нормы.
- **ДРР рекламного**: красные → реклама убивает экономику.
- **Дней запаса** (если включён набор «Остатки»): красные → скоро закончатся.

## 10. Попап деталей артикула

Кликните на карточку любого артикула в таблице — откроется попап с двумя вкладками.

### Вкладка «Кампании»

Показывает, в каких рекламных кампаниях участвует этот SKU и с какими результатами:

- Расход
- Показы, клики, CTR
- Корзины, заказы, модели
- Выручка от рекламы
- ДРР, CPO

Это самый быстрый способ найти **убыточную рекламу для конкретного товара**: открыли карточку, увидели «у этой кампании ДРР 65%» → выключили рекламу артикула в этой кампании, оставили там, где работает.

### Вкладка «Поисковые запросы»

Показывает реальные запросы покупателей, по которым находят этот товар:

- Уникальные пользователи
- Просмотры
- Заказы
- Конверсия (просмотры → заказы)
- Позиция в выдаче

Сортируйте по любой колонке. Самые ценные запросы — где **высокая конверсия + хорошая позиция**. Эти ключевые слова используйте в названиях и описаниях похожих карточек.

---

## 11. Карточки артикулов и попап моделей

Каждая строка артикула в таблице показывает: фото товара, offer_id жирным, SKU серым. Это удобно — визуально узнать товар быстрее, чем читать длинное название.

Кнопка **«Модели»** в toolbar открывает попап управления группировкой (тот же что в Операционке). Можно назначить модель вручную для конкретного SKU или массово через XLSX-импорт.

---

## 12. Что сохраняется в браузере

Юнитка запоминает:

- Период
- Режим группировки
- Активные роли SKU (если выбраны)
- Активный фильтр кампаний
- Активный набор показателей
- Скрытые/показанные колонки
- Цветовые правила по столбцам
- Сортировку

При следующем открытии всё на месте.

!!! tip "Подсказка"
    Если у вас одна и та же типовая работа с Юниткой (например, утром всегда сортировка по убыточным с активным набором «Прибыльность») — настройте один раз и забудьте. Каждое следующее открытие будет в нужном виде.

## 13. Сценарии использования

### Поиск убыточных товаров (5 минут)

1. Кликните пилюлю **«Убыточные»** над таблицей.
2. Гляньте на счётчик SKU и сумму потерь.
3. Откройте каждый артикул кликом по карточке → попап «Кампании».
4. Найдите кампанию с самым высоким ДРР → отключите рекламу в этой кампании в Ozon.

### Аудит рекламы по магазину (15 минут)

1. Включите набор **«Эффективность рекламы»**, период «30 дней».
2. Сортировка по столбцу **«ДРР рекламный»** убыв.
3. Топ-10 — кандидаты на оптимизацию.
4. По каждому → попап → вкладка «Кампании» → находите проблемную.

### Поиск точек роста

1. Кликните пилюлю **«Драйверы роста»**.
2. По каждому артикулу проверьте: реклама запущена?
3. Если рекламы нет — кандидат на запуск (органика уже работает).
4. Если реклама есть и ROAS > 5 — кандидат на увеличение бюджета.

### Подготовка к закупке (10 минут)

1. Активный набор «Остатки», сортировка по «Дням запаса» возр.
2. Топ списка — товары, которые скоро закончатся.
3. Скрестите со «звёздами»: топ-прибыльные товары с малым запасом — приоритет.

### Сбор семантики для новой карточки

1. Откройте топ-3 ваших прибыльных артикула.
2. По каждому → попап → вкладка «Поисковые запросы».
3. Запишите запросы с конверсией 3%+ и хорошим объёмом.
4. Используйте в названии и описании новой похожей карточки.

!!! example "Пример анализа артикула"
    Артикул «Сумка кожаная женская» за 30 дней:

    - Выручка 180 000 ₽, продажи 60 шт, средняя цена 3 000 ₽
    - Себестоимость 90 000 ₽ (50% от выручки)
    - Озон комиссия + фулфилмент 36 000 ₽ (20%)
    - Реклама 18 000 ₽ (10%, ДРР рекламный 18%)
    - **Прибыль 36 000 ₽, маржа 20%**, бейдж ABC = B

    Артикул в роли «Кэш-машина» (маржа выше 15%). На первый взгляд — нормально. Но сравните с топ-5 в магазине, где средняя маржа 35% и ROAS 4.5+. Эта сумка — крепкий середняк, не «звезда». Решение: тест +10% к цене, посмотреть, не упадут ли продажи. Или снизить рекламные ставки, чтобы вытянуть маржу до 25%.

## 14. Что важно помнить

!!! tip "Подсказка"
    Не пытайтесь освоить все 90 метрик сразу. Начните с набора «Прибыльность» — он закрывает 80% задач. Когда поймёте, чего не хватает — переключайтесь на нужный набор или собирайте свой.

!!! warning "Важно"
    Цифры в Юнитке и в ОПиУ должны сходиться по итогу: если сложить «Прибыль» по всем SKU за период, получите чистую прибыль из ОПиУ. Расхождения в пределах 1–2% бывают из-за округлений при распределении транзакций по SKU. Большие расхождения — пишите в поддержку.

!!! tip "Подсказка"
    Юнитка идеально подходит для **стратегических решений** по ассортименту, ценам и рекламе. Для оперативного управления (каждый день) используйте Операционку — там акцент на динамику.

## Частые ошибки

- **Анализ только выручки без учёта прибыли.** Артикул с выручкой 500 000 ₽ может приносить +50 000 ₽ прибыли (хорошо) или −10 000 ₽ убытка (плохо). Без колонки «Прибыль» вы этого не увидите.
- **Игнорирование расходов на рекламу.** Если ROAS меньше «1 / маржа товара» — реклама убыточна. При марже 25% безубыточный ROAS = 4. Всё ниже — потери.
- **Сравнение товаров из разных категорий без фильтрации.** Маржа 15% у одежды и маржа 15% у электроники — разные истории. Сравнивайте внутри категории.
- **Использование слишком короткого периода.** За 7 дней может быть 2 заказа на артикул, и любая случайная реклама его выручку искажает. Минимум 30 дней для устойчивых выводов.
- **Игнорирование пилюль ролей.** Это самый быстрый фильтр — один клик «Убыточные» открывает все проблемные товары. Многие просматривают всю таблицу глазами вместо этого.
- **Не используют попап деталей артикула.** Кликнули на товар — увидели по каким кампаниям и запросам он реально работает. Без этого попапа Юнитка остаётся «таблицей чисел».

## Частые вопросы

**Какая «нормальная» маржа на Ozon?**
Зависит от категории. Электроника и крупногабарит — часто 10–15%. Одежда и обувь — 25–35%. Косметика, БАДы, товары для дома — 30–50%. Если ваша маржа сильно ниже категорийной нормы, разбирайтесь: либо цена слишком низкая, либо себестоимость завышена, либо реклама съедает.

**Почему по одному артикулу маржа 30%, а ROAS 1.8 — не страдает ли товар?**
Очень даже страдает. ROAS 1.8 для товара с маржой 30% — это потери: безубыточный ROAS = 1 / 0.3 = 3.3. Реклама окупается только при ROAS выше 3.3. Ваш товар держится на марже органических продаж, а реклама вытягивает прибыль вниз. Снижайте ставку или отключайте рекламу артикула.

**Что значит роль «Драйвер роста», если у меня нет рекламы?**
Это значит: маржа выше 5% И заказы выросли на 20%+ к прошлому периоду. Товар разгоняется органически. Реклама не обязательна для этой роли. Но если вложитесь в рекламу при таком тренде — обычно даёт мощный эффект масштабирования.

**Цифры в Юнитке отличаются от ОПиУ. Почему?**
Не должны отличаться по итогу. Если сложить «Прибыль» по всем SKU в Юнитке за тот же период = должно быть равно чистой прибыли ОПиУ. Расхождение в 1–2% — норма (округления). Большое расхождение — баг, пишите в поддержку.

**Почему в Юнитке нет графиков по дням?**
По дизайну. Юнитка — это «снимок» по артикулам за период. Если нужна динамика по дням — открывайте Операционку.

**Что делать с убыточными артикулами?**
Кликните пилюлю «Убыточные» → откройте каждый → попап «Кампании» → найдите проблемную кампанию. Подробный сценарий: [Поиск убыточных товаров](../scenarios/find-unprofitable-products.md).

**ABC-анализ — это что и зачем?**
Знаменитое правило Парето: 20% товаров приносят 80% результата. ABC-анализ автоматически делит ваш ассортимент на три группы (A — топ, B — середина, C — хвост). Сортируйте по ABC и смотрите: ваши A — это «хребет» магазина, их нельзя терять. C — кандидаты на снятие с продаж.

**Что значат колонки в попапе «Поисковые запросы»?**
Это запросы покупателей в поиске Ozon, по которым ваш товар реально показывался. Уникальные пользователи — сколько разных людей искали. Просмотры — сколько раз показалась карточка. Заказы — сколько купили. Конверсия = заказы / просмотры. Позиция — где ваш товар в выдаче по этому запросу. Чем выше конверсия + чем выше позиция — тем ценнее запрос для вас.

**Как сохранить набор настроек на постоянной основе?**
Период, фильтры по ролям и кампаниям, активный пресет, сортировка, скрытые колонки — всё это автоматически сохраняется в браузере. Один раз настроили — каждый раз открываете в нужном виде.
