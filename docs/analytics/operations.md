# Операционка

«Операционка» — главный ежедневный отчёт STPulse. За ним сидят каждое утро 5–10 минут, чтобы понять: всё ли в порядке с продажами, рекламой и прибылью, не подкрался ли убыточный день, не сломалась ли воронка по ключевому товару. Если ОПиУ — это «отчёт инвестору раз в месяц», то Операционка — «температурный лист пациента»: одни и те же показатели каждый день, и любое отклонение видно сразу.

В отчёте десятки настроек: режимы группировки, выбор периода, наборы показателей, скрытие столбцов, стрелки динамики, прогнозы. Этот раздел проводит по всем возможностям — чтобы вы знали, что есть, и могли вытащить из отчёта максимум под свою задачу.

Данные доступны только для Ozon.

---

## 1. Где найти и общий вид

1. Откройте **Аналитика → Операционка**.
2. В шапке выберите магазин (или несколько — для сводного отчёта).
3. По умолчанию открывается режим **«Сводно»** за последние 30 дней.

В верхней части — toolbar с настройками: выбор периода, режимы группировки, наборы показателей, дополнительные кнопки. Под ним — большая таблица с метриками в строках и днями/неделями в колонках.

---

## 2. Выбор периода

Кнопка **«Период»** открывает попап, в котором можно:

- **Выбрать год** — переключатели стрелок ◀ ▶.
- **Выбрать месяцы** — сетка 4×3, можно отметить один или несколько подряд.
- **Быстрые кнопки** — **«7 дней»**, **«14 дней»**, **«28 дней»** для типичных оперативных задач.
- **Подтвердить выбор** — кнопка «Применить» внизу попапа.

Максимальная длина периода — **2 месяца**. Это намеренное ограничение: на больших периодах теряется главная ценность Операционки — дневная динамика.

---

## 3. Четыре режима группировки

Чипы в toolbar переключают между четырьмя представлениями данных:

- **Сводно** — общие цифры по магазину за период. Один столбец метрик слева, дни/недели справа. Самый быстрый и часто используемый режим.
- **Категории** — те же метрики, но в разбивке по категориям товаров. Раскрытие группы показывает артикулы внутри.
- **Модели** — разбивка по моделям (если вы их назначили). Полезно для одежды/обуви, где одна модель имеет много размеров.
- **Артикулы** — плоский список всех SKU магазина с пагинацией по 50 за страницу.

В режимах «Категории» и «Модели» дополнительно есть переключатель **«С артикулами / Без артикулов»** — если выключить, увидите только итоги по группам без детализации.

При раскрытии группы первые 5 групп подгружают артикулы автоматически, остальные — по клику «Нажмите для загрузки».

---

## 4. Дни или недели

Чип **«Дни / Недели»** в toolbar переключает шкалу колонок:

- **Дни** — каждый день отдельной колонкой. Лучше всего на коротких периодах (7–14 дней).
- **Недели** — суммы за каждую неделю. Удобно при периоде месяц-два, когда дневной шум мешает.

Пустые колонки (без данных за день/неделю) автоматически скрываются.

---

## 5. Что показано в таблице

Таблица состоит из двух больших блоков:

### Финансовые показатели

- **Заказы**, **выкупы**, **выручка**, **себестоимость**, **расходы Озон**, **продвижение**, **прибыль** — основа экономики.
- Каждая строка показывает значение за весь период + по каждому дню/неделе.
- Под рублёвыми строками может быть дополнительное число — **штуки** (для продаж, заказов, выкупов).

### Воронка продаж — трёхуровневая

Воронка раскрывает путь покупателя: **показы → клики → корзины → заказы**. Каждый уровень разбит на:

- **Total** — общее значение
- **Без рекламы** — органика
- **Реклама** — данные из Performance API

Под каждым уровнем считаются конверсии: **CTR** (клики/показы), **CTC** (корзины/клики), **CTO** (заказы/клики). Дополнительно отображаются заказы по склейке и отмены.

Это позволяет за минуту понять, **на каком этапе теряются деньги**: показы есть, кликов мало → плохая обложка; клики есть, корзин нет → плохая цена; корзины есть, заказов нет → проблема при оформлении.

---

## 6. Наборы показателей (пресеты)

Кнопка **«Показатели»** или **«+ Набор»** — самый мощный инструмент отчёта. Внутри:

- **5 готовых наборов**, которые покрывают типичные задачи:
  - **Прибыльность** — основные финансы и маржа
  - **На 1 единицу** — экономика per-unit
  - **Воронка** — показы / клики / заказы с конверсиями
  - **Эффективность рекламы** — CPM, CPC, CPO, ROAS, ДРР
  - **Реклама и Маркетинг** — рекламные расходы по типам
- **Свои наборы** — выберите галочками нужные метрики, дайте имя, сохраните. В следующий раз переключаете чипом.
- **«Скрыть лишние»** — показывает только метрики из активного набора, остальные скрываются. Если выключено, метрики вне набора показываются с приглушённой прозрачностью.

Наборы сохраняются в браузере — при следующем заходе всё на месте.

---

## 7. Управление столбцами и фокус

Помимо пресетов, есть точечные инструменты:

- **Скрытие отдельной колонки (день/неделя)** — правый клик по заголовку. Между видимыми появится маркер `+N` — клик по нему возвращает скрытое.
- **Цветовая подсветка** — для любого показателя можно задать цвет (через попап настроек метрики). Подсвеченные ячейки видны за секунду — удобно для прибыли, отрицательных значений, проблемных конверсий.
- **Уровни раскрытия** — кнопка с цифрой в кружке (0/1/2/3) в заголовке «Товар». Каждый уровень глубже раскрывает группы. Удобно для быстрого «развернуть всё / свернуть всё».

---

## 8. Стрелки динамики, цвета, прогноз

В дневных и недельных колонках встроены вспомогательные индикаторы:

- **↑ зелёная стрелка** — рост по сравнению с предыдущим периодом.
- **↓ красная стрелка** — падение.
- **Красный шрифт** — отрицательные значения для выручки, прибыли, «к начислению».
- **Прогноз** (последняя колонка справа) — линейная экстраполяция на конец периода: фактическое значение / прошедшие дни × все дни периода. Помогает к 15-му числу прикинуть, каким будет результат месяца.

---

## 9. Дополнительные инструменты

В toolbar есть несколько полезных кнопок:

### Управление моделями

Кнопка **«Модели»** открывает попап для группировки артикулов. Можно:

- Назначить модель вручную для конкретного SKU.
- Скачать XLSX-шаблон со всеми артикулами магазина.
- Загрузить заполненный XLSX — все модели применятся одним импортом.

Назначенные модели сразу появляются в режиме группировки «Модели».

### Бейдж «Без себестоимости (N)»

Если у части товаров не загружена себестоимость, в toolbar появляется красный бейдж с количеством. Клик открывает попап со списком этих SKU и возможностью **внести себестоимость прямо в таблице** — без перехода в раздел «Себестоимость». Удобно для точечных правок.

### Экспорт CSV

Кнопка **«↓ csv»** выгружает текущую таблицу со всеми применёнными фильтрами и пресетами. Полезно для бухгалтера или для своих расчётов в Excel.

### Обзорный тур

Кнопка **«?»** рядом с заголовком запускает короткий обзорный тур — пройдёт по основным элементам с подсказками. Полезно при первом знакомстве.

---

## 10. Карточки артикулов

В режимах «Категории», «Модели» и «Артикулы» каждая строка артикула показывает:

- **Фото товара** (28×28 пикселей)
- **offer_id** жирным шрифтом
- **SKU** серым

Это удобно: визуально узнать товар быстрее, чем читать длинное название. Карточки берутся из импорта Ozon — обновляются автоматически.

---

## 11. Что сохраняется в браузере

Все эти настройки автоматически сохраняются и подтягиваются при следующем входе:

- Выбранный период
- Режим группировки и режим артикулов
- Дни/Недели
- Активный набор показателей
- Скрытые колонки
- Цветовые правила
- Состояние раскрытия групп

Если зайдёте с другого браузера или компьютера — настройки придётся выставить заново.

!!! tip "Подсказка"
    Если у вас стандартная утренняя проверка с одним и тем же набором метрик и периодом — всё это будет открываться одним кликом, без перенастройки. Время на ежедневный обзор — реально 30 секунд после первичной настройки.

---

## 12. Сценарии использования

### Утренняя проверка (5 минут)

1. Период «7 дней», режим «Сводно», набор «Прибыльность».
2. Гляньте на цвет вчерашней прибыли и стрелку динамики.
3. Если красная — переключите на «Категории» или «Артикулы», найдите проблемный SKU.

### Аудит воронки

1. Включите набор «Воронка», период «14 дней».
2. Смотрите конверсии по уровням: где провал — там и проблема.
3. Низкий CTR → плохая обложка карточки. Низкий CTC → высокая цена или плохое описание. Низкий CTO → проблема при оформлении (доставка, остатки).

### Поиск убыточного дня

1. Период «30 дней», набор «Прибыльность», режим «Сводно».
2. Найдите день с красной прибылью.
3. Переключите на «Артикулы», тот же день — увидите, какие SKU дали минус.

### Аудит рекламы

1. Набор «Эффективность рекламы», период «14 дней», режим «Артикулы».
2. Сортировка по столбцу «ДРР рекламный» убыв.
3. Топ-список — кандидаты на оптимизацию.

!!! example "Пример"
    Магазин одежды. В понедельник 14 апреля прибыль за день вдруг упала до 12 000 ₽ при средней 35 000 ₽.

    Откройте «Операционку», период «14 дней», набор «Прибыльность». Сразу видно: 14 апреля — красная ячейка по прибыли. Переключите на «Артикулы», тот же день — видно, что SKU «Свитер мужской зимний» сделал 15 заказов, а в субботу делал 3. Откройте набор «Эффективность рекламы», тот же артикул — ДРР рекламный **62%** (норма 20%). Реклама сжигает прибыль. Решение: снизить ставку или отключить эту кампанию. **Анализ занял 5 минут**, спасли ~150 000 ₽ за следующие 7 дней.

---

## 13. Что важно помнить

!!! tip "Подсказка"
    Не пытайтесь освоить все 5 предустановленных наборов сразу. Начните с «Прибыльности» — она покрывает 80% повседневных задач. Когда поймёте, чего не хватает — переключите на нужный набор или соберите свой.

!!! warning "Важно"
    Операционка ограничена 2 месяцами по периоду. Если нужно посмотреть итог квартала или года — это к ОПиУ. Здесь — про ежедневный пульс.

!!! tip "Подсказка"
    Сводный режим («Сводно») считается с серверным кэшем 5 минут — это самый быстрый. Категории и Модели грузят данные побольше, могут открываться 1–3 секунды. Артикулы для крупного магазина (1000+ SKU) — самый тяжёлый режим, лучше использовать с фильтром по поиску.

## Частые ошибки

- **Слишком большой период** — теряется динамика. На 60 днях все выходные «сливаются», нельзя поймать просадку конкретного понедельника. Берите 7–14 дней для оперативной работы.
- **Анализ только сумм, без просмотра дней** — итоговая прибыль за месяц 200 000 ₽, а внутри было 5 убыточных дней подряд из-за неудачной рекламной кампании. Сводная цифра это скрывает, дни — показывают.
- **Игнорирование воронки продаж** — смотрят только на выручку, не разбираются, почему она такая. А ответ часто в воронке.
- **Отсутствие цветовой подсветки** — без неё аномальные значения теряются среди обычных. С ней проблема видна за секунду — красная ячейка цепляет глаз.
- **Включают все метрики сразу** — таблица становится нечитаемой. Используйте наборы или соберите свой компактный пресет на 5–7 главных метрик.
- **Забывают про пресет «Эффективность рекламы»** — все рекламные данные уже сгруппированы, не нужно их собирать вручную.

## Частые вопросы

**Можно ли смотреть Операционку за квартал или за год?**
Технически нет — отчёт ограничен 2 месяцами. Это сделано намеренно: на больших периодах теряется главная ценность Операционки — дневная динамика. Для квартальных и годовых итогов используйте Прибыли и убытки.

**Почему данные за сегодня неполные?**
Финансовые транзакции от Ozon приходят с задержкой 1–3 дня. Сегодняшний день — это «первая прикидка», цифры будут уточняться в течение 2–3 суток. Серьёзные выводы делайте по дню, который старше 2–3 дней.

**Воронка показывает 100 000 показов и 0 кликов. Это нормально?**
Нет, это либо сбой импорта рекламы, либо реклама вообще не работает. Проверьте: Performance API подключён? В кабинете Ozon кампания активна? Если всё в порядке — пишите в поддержку.

**Сводные данные сверху отчёта отличаются от суммы по дням. Почему?**
Не должны отличаться. Если видите расхождение — это баг, пишите в поддержку. Сводные = SUM(дневные значения) по определению.

**Конверсия в Операционке отличается от конверсии в Юнитке. В чём разница?**
В Операционке конверсия считается по магазину целиком за каждый день. В Юнитке — по конкретному артикулу за весь период. Это разные числа, отвечающие на разные вопросы.

**Как сохранить привычный набор настроек на каждое утро?**
Один раз настройте: период, режим, набор показателей, скрытые колонки. Всё это запомнится в браузере. Утром просто открывайте Операционку — увидите всё в том же виде.

**Зачем нужен прогноз, если он линейный?**
Это грубая прикидка «если темп сохранится». Полезно к середине месяца увидеть, выполнится ли план. Точный прогноз с учётом сезонности — задача для Планирования, не для Операционки.

**Что делать, если в группе много артикулов, и не хочется грузить все?**
Используйте поиск в шапке (по offer_id или названию) — он отфильтрует таблицу мгновенно. Или сразу переключайтесь на режим «Артикулы» с пагинацией.

---

Операционка — главный инструмент ежедневного управления бизнесом. Если ОПиУ — это «отчёт инвестору», то Операционка — «температурный лист пациента»: каждый день одни и те же показатели, и любое отклонение сразу видно. Утренние 10 минут в этом разделе помогают поймать проблемы раньше, чем они станут катастрофой.
